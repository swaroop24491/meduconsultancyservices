# meduconsultancyservices
Static website for EPF &amp; ESI consultancy firm.

Available in English (root URLs) and Kannada (`/kn/` prefix). Kannada covers the
non-location pages (home, about, contact, the three service pages, the EPF
Excel-to-Text converter, privacy policy, and terms) and all 22 location pages
(`/kn/epf-esi-consultancy-<city>`). English and Kannada counterparts are linked
with `hreflang` tags and a header/menu language switch.
