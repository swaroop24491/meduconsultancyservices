How to make the text file by hand

You can also do this yourself in Excel and Notepad:

  1. Open your filled ECR Excel sheet. Delete the heading row and any empty rows.
  2. Save it as CSV: File → Save As → CSV (Comma delimited). Close Excel.
  3. Right-click the CSV file and open it with Notepad.
  4. Replace every comma with #~#: Edit → Replace, type , and #~#, then Replace All.
  5. Save it as a .txt file, with no spaces in the file name.

This goes wrong if a name or number has a comma in it, or if Excel shows a UAN (the employee's PF account number) as 1.00123E+11. The converter avoids both.

Note: The converter only changes the file format. It does not check your figures. Check the amounts before you upload the file to EPFO.
