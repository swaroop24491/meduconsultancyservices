ESIನಲ್ಲಿ 7 ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು, ಮತ್ತು ಅವುಗಳನ್ನು ಸರಿಪಡಿಸುವುದು ಹೇಗೆ

ಹೆಚ್ಚಿನ ESI ಸಮಸ್ಯೆಗಳು ತಿಳಿಯದೆ ಆಗುವ ತಪ್ಪುಗಳು. ತಿಂಗಳುಗಳು ಕಳೆದಂತೆ ಅವು ದೊಡ್ಡದಾಗುತ್ತವೆ. ನಾವು ಹೆಚ್ಚಾಗಿ ನೋಡುವ ಏಳು ತಪ್ಪುಗಳು ಇಲ್ಲಿವೆ, ಪ್ರತಿಯೊಂದಕ್ಕೂ ಒಂದು ಸರಳ ಪರಿಹಾರ.

{{ site.data.facts.tools_checked_kn }}ರಂದು ನಿಯಮಗಳನ್ನು ಪರಿಶೀಲಿಸಲಾಗಿದೆ

1. ESI 20 ಸಿಬ್ಬಂದಿಯಿಂದ ಆರಂಭ ಎಂದುಕೊಳ್ಳುವುದು

10 ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇದ್ದರೆ ESI ಅನ್ವಯಿಸುತ್ತದೆ, ಎಲ್ಲ ರಾಜ್ಯಗಳಲ್ಲೂ.

ಪರಿಹಾರ: ಸಿಬ್ಬಂದಿಯನ್ನು ಸರಿಯಾಗಿ ಎಣಿಸಿ (ಕೆಳಗೆ ನೋಡಿ). ESI 10ರಿಂದಲೇ ಆರಂಭ. ನಮ್ಮ ಉಚಿತ {% include link.html path="esi-eligibility-checker" label="ESI ಅರ್ಹತೆ ಪರಿಶೀಲನೆ" arrow=false %} ಬಳಸಿ, ಅಥವಾ ಓದಿ: {% include link.html path="blogs/esi-applicability-threshold" label="ESI: ಯಾರು ನೋಂದಣಿ ಮಾಡಬೇಕು" arrow=false %}.

ಕೆಲವು ಅಪಾಯಕಾರಿ ಕೆಲಸಗಳಿಗೆ, 1 ಉದ್ಯೋಗಿ ಇದ್ದರೂ ESI ಅನ್ವಯಿಸಬಹುದು. ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

2. ಸಿಬ್ಬಂದಿಯನ್ನು ತಪ್ಪಾಗಿ ಎಣಿಸುವುದು

ತಾತ್ಕಾಲಿಕ ಮತ್ತು ದಿನಗೂಲಿ ಸಿಬ್ಬಂದಿ, ಗುತ್ತಿಗೆದಾರರು ಕಳುಹಿಸುವ ಸಿಬ್ಬಂದಿ ಹಾಗೂ ತಿಂಗಳಿಗೆ ₹21,000ಕ್ಕಿಂತ ಹೆಚ್ಚು ಗಳಿಸುವ ಸಿಬ್ಬಂದಿ (ESI ವೇತನ ಮಿತಿ) ಎಲ್ಲರೂ 10ರಲ್ಲಿ ಲೆಕ್ಕಕ್ಕೆ ಬರುತ್ತಾರೆ. ವ್ಯಾಪಾರದಲ್ಲಿ ಕೆಲಸ ಮಾಡುವ, ಸಂಬಳ ಪಡೆಯುವ ನಿರ್ದೇಶಕರು ಇದ್ದಾರೆಯೇ? ಅವರನ್ನು ಹೇಗೆ ಎಣಿಸಬೇಕು ಎಂದು ತಿಳಿಯಲು ನಮಗೆ ಕರೆ ಮಾಡಿ. ಅಪ್ರೆಂಟಿಸ್‌ಗಳು, ಮಾಲೀಕರು ಮತ್ತು ಪಾಲುದಾರಿಕೆ ಸಂಸ್ಥೆಯ ಪಾಲುದಾರರು ಲೆಕ್ಕಕ್ಕೆ ಬರುವುದಿಲ್ಲ.

ಪರಿಹಾರ: ಲೆಕ್ಕಕ್ಕೆ ಬರುವ ಎಲ್ಲರನ್ನೂ ಎಣಿಸಿ.

3. ESI ವೇತನದ ಬದಲು ಪೂರ್ತಿ ಸಂಬಳ ಬಳಸುವುದು

ESI ವೇತನ ಪೂರ್ತಿ ಸಂಬಳ ಅಲ್ಲ. ಮನೆ ಬಾಡಿಗೆ ಭತ್ಯೆ (HRA), ಓವರ್‌ಟೈಮ್, ಬೋನಸ್, ಕಮಿಷನ್ ಮತ್ತು ಪ್ರಯಾಣ ಭತ್ಯೆಯನ್ನು ಸೇರಿಸುವುದಿಲ್ಲ. ಆದರೆ ESI ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು ESI ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

ಪರಿಹಾರ: ₹21,000 ಮಿತಿಯನ್ನು ಪರಿಶೀಲಿಸುವ ಮೊದಲು, ಪ್ರತಿಯೊಬ್ಬರ ESI ವೇತನವನ್ನು ಲೆಕ್ಕ ಹಾಕಿ. ನಮ್ಮ ಉಚಿತ {% include link.html path="esi-contribution-calculator" label="ESI ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರ" arrow=false %} ಬಳಸಿ ನೋಡಿ.

{% include result-call.html line="ಈ ತಪ್ಪುಗಳನ್ನು ತಪ್ಪಿಸಬೇಕೇ? ನಮಗೆ ಕರೆ ಮಾಡಿ. ನಿಮ್ಮ ESI ಅನ್ನು ಪ್ರತಿ ತಿಂಗಳು ನಾವು ಫೈಲ್ ಮಾಡುತ್ತೇವೆ." %}

4. ಕಡಿಮೆ ಸಂಬಳದ ಸಿಬ್ಬಂದಿಗೆ ನಿಮ್ಮ ಪಾಲನ್ನು ಬಿಟ್ಟುಬಿಡುವುದು

ದಿನದ ಸಂಬಳ ತುಂಬಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ ಉದ್ಯೋಗಿಯ ಪಾಲನ್ನು (0.75%) ಕಟ್ಟುವುದಿಲ್ಲ. ನಿಮ್ಮ ಪಾಲನ್ನು (3.25%) ನೀವು ಕಟ್ಟಲೇಬೇಕು.

ಪರಿಹಾರ: ನಿಮ್ಮ 3.25% ಅನ್ನು ನೀವು ಕಟ್ಟಲೇಬೇಕು. ನಮಗೆ ಕರೆ ಮಾಡಿ, ಪ್ರತಿಯೊಬ್ಬರನ್ನೂ ನಾವು ಪರಿಶೀಲಿಸುತ್ತೇವೆ.

5. ESI ಅನ್ನು ಬೇಗನೆ ನಿಲ್ಲಿಸುವುದು

ಸಂಬಳ ₹21,000 ದಾಟಿದಾಗ, ಇಲ್ಲಿ ತಪ್ಪು ಮಾಡುವುದು ಸುಲಭ.

ಪರಿಹಾರ: ನೀವೇ ನಿಲ್ಲಿಸಬೇಡಿ. ಆ ವ್ಯಕ್ತಿಗೆ ESI ಯಾವಾಗ ನಿಲ್ಲಬಹುದು ಎಂದು ತಿಳಿಯಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

6. 15ನೇ ತಾರೀಖಿನ ನಂತರ ಕಟ್ಟುವುದು

ESI ಅನ್ನು ಮುಂದಿನ ತಿಂಗಳ 15ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು. ತಡವಾಗಿ ಕಟ್ಟಿದರೆ ಬಡ್ಡಿ ಕಟ್ಟಬೇಕು, ಮತ್ತು ಡ್ಯಾಮೇಜಸ್ (ದಂಡದಂತಹ ಹೆಚ್ಚುವರಿ ಮೊತ್ತ) ಕೂಡ ಕಟ್ಟಬೇಕಾಗಬಹುದು.

ಪರಿಹಾರ: ಕೆಲವು ದಿನಗಳು ಮುಂಚಿತವಾಗಿಯೇ, 15ನೇ ತಾರೀಖಿನ ಮೊದಲು ಕಟ್ಟಿ. ಓದಿ: {% include link.html path="blogs/esi-late-payment-penalty" label="ESI ತಡವಾಗಿ ಕಟ್ಟಿದರೆ ಎಷ್ಟು ಆಗುತ್ತದೆ" arrow=false %}.

7. ಹೊಸ ಸಿಬ್ಬಂದಿಯನ್ನು ಮೊದಲ ದಿನದಿಂದಲೇ ಸೇರಿಸದಿರುವುದು

ESIನಲ್ಲಿ ಇರಬೇಕಾದ ಪ್ರತಿ ಉದ್ಯೋಗಿಗೂ IP ಸಂಖ್ಯೆ (ಉದ್ಯೋಗಿಯ ESI ಸಂಖ್ಯೆ) ಬೇಕು.

ಪರಿಹಾರ: ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ, ಪ್ರತಿ ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು ಅವರು ಸೇರಿದ ಕೂಡಲೇ ಸೇರಿಸಿ. ನಮ್ಮ ಗ್ರಾಹಕರಿಗಾಗಿ ESIC ಪೋರ್ಟಲ್‌ನಲ್ಲಿ IP ಸಂಖ್ಯೆಗಳನ್ನು ನಾವು ಮಾಡಿಕೊಡುತ್ತೇವೆ. ಓದಿ: {% include link.html path="blogs/esi-inspection-guide" label="ESI ತಪಾಸಣೆಯಲ್ಲಿ ಏನಾಗುತ್ತದೆ" arrow=false %}.
