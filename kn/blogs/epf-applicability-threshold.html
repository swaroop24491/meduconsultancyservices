ನೀವು PF ನೋಂದಣಿ ಮಾಡಬೇಕೇ?

ಹೌದು, ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ {{ epf.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇದ್ದರೆ. ಎಲ್ಲರನ್ನೂ ಎಣಿಸಿ: ತಾತ್ಕಾಲಿಕ ಮತ್ತು ದಿನಗೂಲಿ ಸಿಬ್ಬಂದಿ ಹಾಗೂ ಗುತ್ತಿಗೆದಾರರು ಕಳುಹಿಸುವ ಸಿಬ್ಬಂದಿಯೂ ಸೇರಿ. ಒಮ್ಮೆ PF ಅನ್ವಯಿಸಿದರೆ, ನಂತರ ಸಿಬ್ಬಂದಿ {{ epf.min_employees }}ಕ್ಕಿಂತ ಕಡಿಮೆಯಾದರೂ ಅದು ಅನ್ವಯಿಸುತ್ತಲೇ ಇರುತ್ತದೆ.

{{ site.data.facts.tools_checked_kn }}ರಂದು ನಿಯಮಗಳನ್ನು ಪರಿಶೀಲಿಸಲಾಗಿದೆ

20 ಸಿಬ್ಬಂದಿಯ ನಿಯಮ

PF (ಭವಿಷ್ಯ ನಿಧಿ, EPF ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) {{ epf.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇರುವ ಯಾವುದೇ ಉದ್ಯಮದ ಯಾವುದೇ ವ್ಯಾಪಾರಕ್ಕೆ ಅನ್ವಯಿಸುತ್ತದೆ. ಸರಿಯಾಗಿ {{ epf.min_employees }} ಇದ್ದರೂ ಅನ್ವಯಿಸುತ್ತದೆ.

ಒಮ್ಮೆ PF ಅನ್ವಯಿಸಿದರೆ, ನಂತರ ಸಿಬ್ಬಂದಿ {{ epf.min_employees }}ಕ್ಕಿಂತ ಕಡಿಮೆಯಾದರೂ ಅದು ಮುಂದುವರಿಯುತ್ತದೆ.

{{ epf.min_employees }}ಕ್ಕಿಂತ ಕಡಿಮೆ ಸಿಬ್ಬಂದಿ ಇದ್ದಾರೆಯೇ? ಸದ್ಯಕ್ಕೆ ನೀವು PF ನೋಂದಣಿ ಮಾಡಬೇಕಿಲ್ಲ. ನಮಗೆ ಕರೆ ಮಾಡಿ, ನಿಮ್ಮ ವಿಷಯವನ್ನು ನಾವು ಪರಿಶೀಲಿಸುತ್ತೇವೆ.

ಕೆಲಸ ಹೆಚ್ಚಿರುವ ಕಾಲದಲ್ಲಿ ಹೆಚ್ಚುವರಿ ಸಿಬ್ಬಂದಿಯನ್ನು ನೇಮಿಸುತ್ತೀರಾ? ಅವರನ್ನೂ ಎಣಿಸಿ. ನೀವು {{ epf.min_employees }} ತಲುಪಿದರೆ, PF ನಿಮಗೆ ಹೇಗೆ ಅನ್ವಯಿಸುತ್ತದೆ ಎಂದು ತಿಳಿಯಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

20ರಲ್ಲಿ ಯಾರನ್ನು ಎಣಿಸಬೇಕು

ಇವರೆಲ್ಲರನ್ನೂ ಎಣಿಸಿ:

  • ಕಾಯಂ ಸಿಬ್ಬಂದಿ
  • ತಾತ್ಕಾಲಿಕ ಮತ್ತು ದಿನಗೂಲಿ ಸಿಬ್ಬಂದಿ
  • ಗುತ್ತಿಗೆದಾರರು ಕಳುಹಿಸುವ ಸಿಬ್ಬಂದಿ
  • ತಿಂಗಳಿಗೆ ₹25,000ಕ್ಕಿಂತ ಹೆಚ್ಚು ಗಳಿಸುವ ಸಿಬ್ಬಂದಿ (PF ವೇತನ ಮಿತಿ)

ಎಣಿಸಬೇಡಿ: ಅಪ್ರೆಂಟಿಸ್‌ಗಳು, ಮಾಲೀಕರು (ಒಬ್ಬರೇ ವ್ಯಾಪಾರದ ಮಾಲೀಕರಾಗಿದ್ದರೆ), ಮತ್ತು ಪಾಲುದಾರಿಕೆ ಸಂಸ್ಥೆಯ ಪಾಲುದಾರರು.

ಸಂಬಳ ಪಡೆಯುವ ನಿರ್ದೇಶಕರು ಇದ್ದಾರೆಯೇ? ಅವರನ್ನು ಹೇಗೆ ಎಣಿಸಬೇಕು ಎಂದು ತಿಳಿಯಲು ನಮಗೆ ಕರೆ ಮಾಡಿ. ನಿಮ್ಮ ವ್ಯಾಪಾರ LLP (ಸೀಮಿತ ಹೊಣೆಗಾರಿಕೆಯ ಪಾಲುದಾರಿಕೆ) ಆಗಿದೆಯೇ? ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

ಯಾವ ಸಿಬ್ಬಂದಿ PFಗೆ ಸೇರಬೇಕು

PF ವೇತನ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿಗೆ PF ಕಡ್ಡಾಯ. ಇದು {{ epf.wage_ceiling_from_kn }}ರಿಂದ ಬಂದ ಹೊಸ ಮಿತಿ. ಅದಕ್ಕಿಂತ ಮೊದಲು ಇದು {{ epf.wage_ceiling_old_text }} ಇತ್ತು.

PF ವೇತನ ಎಂದರೆ ಮೂಲ ವೇತನ ಮತ್ತು DA (ತುಟ್ಟಿ ಭತ್ಯೆ: ಬೆಲೆ ಏರಿದಂತೆ ಹೆಚ್ಚಾಗುವ ಭತ್ಯೆ), ಪೂರ್ತಿ ಸಂಬಳ ಅಲ್ಲ. ಆದರೆ PF ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು PF ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

PF ವೇತನ {{ epf.wage_ceiling_text }} ದಾಟಿದೆಯೇ? ನೀವು ಮತ್ತು ಉದ್ಯೋಗಿ ಇಬ್ಬರೂ ಲಿಖಿತವಾಗಿ ಒಪ್ಪಿದರೆ, ಹೊಸದಾಗಿ ಸೇರುವವರು ಆಗಲೂ ಸೇರಬಹುದು. ಈಗಾಗಲೇ ಸದಸ್ಯರಾಗಿರುವ ಸಿಬ್ಬಂದಿ ಸದಸ್ಯರಾಗಿಯೇ ಉಳಿಯುತ್ತಾರೆ.

ಸಂಬಳದ ನಿಯಮಗಳು ಬದಲಾಗುತ್ತಿವೆಯೇ? ನಮಗೆ ಕರೆ ಮಾಡಿ. ಇದನ್ನು ನಾವು ನಿಮಗಾಗಿ ಪರಿಶೀಲಿಸುತ್ತೇವೆ.

ತಡವಾಗಿ ನೋಂದಣಿ ಮಾಡಿದರೆ

ನೀವು ಮೊದಲೇ ನೋಂದಣಿ ಮಾಡಬೇಕಿದ್ದರೆ, ಹಿಂದಿನ ತಿಂಗಳುಗಳ PF ಅನ್ನು ಬಡ್ಡಿ ಮತ್ತು ದಂಡದೊಂದಿಗೆ ಕಟ್ಟಬೇಕಾಗಬಹುದು. PF ಅನ್ವಯಿಸಿದ ಕೂಡಲೇ ನೋಂದಣಿ ಮಾಡಿ. ನಮಗೆ ಕರೆ ಮಾಡಿ, ನಾವು ನಿಮ್ಮ ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ.
