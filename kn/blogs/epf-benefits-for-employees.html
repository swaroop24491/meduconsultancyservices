ಉದ್ಯೋಗಿಗಳಿಗೆ PF ಸೌಲಭ್ಯಗಳು: ನಿಮಗೆ ಏನು ಸಿಗುತ್ತದೆ

PF ನಿಮ್ಮ ಭವಿಷ್ಯಕ್ಕಾಗಿ ಒಂದು ಉಳಿತಾಯ ಖಾತೆ. ಪ್ರತಿ ತಿಂಗಳು ನಿಮ್ಮ ಸಂಬಳದಿಂದ ಹಣ ಅದಕ್ಕೆ ಹೋಗುತ್ತದೆ, ಮತ್ತು ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರೂ ಹಣ ಸೇರಿಸುತ್ತಾರೆ. ಇದರಿಂದ ನಿಮಗೆ ಪಿಂಚಣಿ ಮತ್ತು ವಿಮೆಯೂ ಸಿಗಬಹುದು. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರ ವ್ಯಾಪಾರದಲ್ಲಿ {{ site.data.facts.epf.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇದ್ದು, ನಿಮ್ಮ PF ವೇತನ {{ site.data.facts.epf.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇದ್ದರೆ, ಸೇರುವುದು ಕಡ್ಡಾಯ.

ಉದ್ಯೋಗದಾತರೇ? ಈ ಪುಟವನ್ನು ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಯೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳಿ.

{{ site.data.facts.tools_checked_kn }}ರಂದು ನಿಯಮಗಳನ್ನು ಪರಿಶೀಲಿಸಲಾಗಿದೆ

PF ಎಂದರೇನು

PF (ಭವಿಷ್ಯ ನಿಧಿ, EPF ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) ಸರ್ಕಾರದ PF ಇಲಾಖೆಯಾದ EPFO ನಡೆಸುವ ಉಳಿತಾಯ ಯೋಜನೆ. ಪ್ರತಿ ತಿಂಗಳು, ನಿಮ್ಮ PF ವೇತನದ 12% ನಿಮ್ಮದೇ PF ಖಾತೆಗೆ ಹೋಗುತ್ತದೆ. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ಇನ್ನೊಂದು 12% ಕಟ್ಟುತ್ತಾರೆ. PF ವೇತನ ಎಂದರೆ ಮೂಲ ವೇತನ ಮತ್ತು DA (ತುಟ್ಟಿ ಭತ್ಯೆ: ಬೆಲೆ ಏರಿದಂತೆ ಹೆಚ್ಚಾಗುವ ಭತ್ಯೆ), ನಿಮ್ಮ ಪೂರ್ತಿ ಸಂಬಳ ಅಲ್ಲ. ಆದರೆ ನಿಮ್ಮ PF ವೇತನ ನಿಮ್ಮ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು ನಿಮ್ಮ PF ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

ನಿಮಗೆ ಏನು ಸಿಗುತ್ತದೆ

  • ಉಳಿತಾಯ. ನಿಮ್ಮ PF ಉಳಿತಾಯ ನಿಮ್ಮ ಹೆಸರಿನಲ್ಲಿ ಇರುತ್ತದೆ. ಅದಕ್ಕೆ ಬಡ್ಡಿ ಸಿಗಬಹುದು. ಬಡ್ಡಿ ದರವನ್ನು ಸರ್ಕಾರ ಪ್ರತಿ ವರ್ಷ ನಿಗದಿಪಡಿಸುತ್ತದೆ. ನೀವು ಕೆಲಸ ಬದಲಿಸಿದಾಗಲೂ ನಿಮ್ಮ UAN (ನಿಮ್ಮ PF ಸಂಖ್ಯೆ) ಅದೇ ಇರುತ್ತದೆ.
  • ಪಿಂಚಣಿ. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರ 12%ನ ಒಂದು ಭಾಗ ಪಿಂಚಣಿ ಯೋಜನೆಗೆ ಹೋಗುತ್ತದೆ (EPS, PFನ ಪಿಂಚಣಿ ನಿಧಿ). ಇದರಿಂದ ಮುಂದೆ ನಿಮಗೆ ಪಿಂಚಣಿ ಸಿಗಬಹುದು. ಪಿಂಚಣಿ ನಿಯಮಗಳನ್ನು EPFO ನಿಗದಿಪಡಿಸುತ್ತದೆ. ವಿವರಗಳಿಗೆ ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರನ್ನು ಕೇಳಿ.
  • ವಿಮೆ. PF ಸದಸ್ಯತ್ವದಲ್ಲಿ ನಿಮ್ಮ ಕುಟುಂಬಕ್ಕೆ ವಿಮಾ ರಕ್ಷಣೆಯೂ ಇರಬಹುದು. ವಿವರಗಳಿಗೆ ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರನ್ನು ಕೇಳಿ.

ನೀವು ಏಕೆ ಬೇಡ ಎನ್ನುವಂತಿಲ್ಲ

ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರ ವ್ಯಾಪಾರದಲ್ಲಿ {{ site.data.facts.epf.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇದ್ದು, ನಿಮ್ಮ PF ವೇತನ ತಿಂಗಳಿಗೆ {{ site.data.facts.epf.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇದ್ದಾಗ PF ಕಡ್ಡಾಯ. ಇದು {{ site.data.facts.epf.wage_ceiling_from_kn }}ರಿಂದ ಇರುವ ಮಿತಿ. ನೀವು ಬೇಡ ಎನ್ನುವಂತಿಲ್ಲ, ಮತ್ತು ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ನಿಮ್ಮನ್ನು ಬಿಟ್ಟುಬಿಡುವಂತಿಲ್ಲ. ನೀವು ಈಗಾಗಲೇ PF ಸದಸ್ಯರಾಗಿದ್ದರೆ, ನೀವು ಕೇಳಿದ್ದಕ್ಕೋ ನಿಮ್ಮ ಸಂಬಳ ಹೆಚ್ಚಾಗಿದ್ದಕ್ಕೋ PF ನಿಲ್ಲಿಸಲು ಆಗುವುದಿಲ್ಲ.

ನಿಮ್ಮ PF ವೇತನ {{ site.data.facts.epf.wage_ceiling_text }} ದಾಟಿದೆ ಮತ್ತು ನೀವು ಹೊಸದಾಗಿ ಸೇರುತ್ತಿದ್ದೀರಾ? ನೀವು ಮತ್ತು ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ಇಬ್ಬರೂ ಲಿಖಿತವಾಗಿ ಒಪ್ಪಿದರೆ, ನೀವು ಆಗಲೂ ಸೇರಬಹುದು. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರನ್ನು ಕೇಳಿ.

ನನ್ನ ಕೈಗೆ ಬರುವ ಸಂಬಳ ಕಡಿಮೆಯಾಗುತ್ತದೆಯೇ?

ಹೌದು. ನಿಮ್ಮ PF ವೇತನದ 12% ನಿಮ್ಮ ಕೈಗೆ ಬರುವ ಬದಲು ನಿಮ್ಮ PF ಖಾತೆಗೆ ಹೋಗುತ್ತದೆ. ಉದಾಹರಣೆ: ನಿಮ್ಮ PF ವೇತನ ತಿಂಗಳಿಗೆ ₹20,000. ನೀವು ₹2,400 ಕಟ್ಟುತ್ತೀರಿ. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರೂ ₹2,400 ಕಟ್ಟುತ್ತಾರೆ, ಮತ್ತು ಅದರ ಒಂದು ಭಾಗ ನಿಮ್ಮ ಪಿಂಚಣಿಗೆ (EPS) ಹೋಗುತ್ತದೆ. ನಿಮ್ಮದೇ ಮೊತ್ತವನ್ನು ನಮ್ಮ ಉಚಿತ PF ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರದಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.

ನಿಮ್ಮ PF ಅನ್ನು ಪರಿಶೀಲಿಸುವುದು ಹೇಗೆ

ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರಿಂದ ನಿಮ್ಮ UAN ಕೇಳಿ. ಇನ್ನೂ UAN ಇಲ್ಲದ ಹೊಸ ಸಿಬ್ಬಂದಿ UMANG ಆ್ಯಪ್‌ನಲ್ಲಿ (ಸರ್ಕಾರದ ಮೊಬೈಲ್ ಆ್ಯಪ್) ಬೇಗ ಮುಗಿಯುವ ಮುಖದ ಸ್ಕ್ಯಾನ್ ಮೂಲಕ UAN ಪಡೆಯುತ್ತಾರೆ. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ಇದರಲ್ಲಿ ನಿಮಗೆ ಸಹಾಯ ಮಾಡಬಹುದು. ನಂತರ ಪ್ರತಿ ತಿಂಗಳು ನಿಮ್ಮ PF ಜಮೆಯಾಗಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ.
