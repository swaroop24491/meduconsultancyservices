ESIನಿಂದ ನಿಮಗೆ ಏನು ಸಿಗುತ್ತದೆ?

ESI (ಉದ್ಯೋಗಿಗಳ ರಾಜ್ಯ ವಿಮೆ) ನಿಮಗೆ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ನೀಡುತ್ತದೆ, ಮತ್ತು ನೀವು ಅನಾರೋಗ್ಯದಲ್ಲಿದ್ದಾಗ, ಗಾಯಗೊಂಡಾಗ ಅಥವಾ ಹೆರಿಗೆಯ ಸಮಯದಲ್ಲಿ ಹಣದ ಸಹಾಯ ನೀಡುತ್ತದೆ. ನೀವು ಸ್ವಲ್ಪ ಭಾಗ ಕಟ್ಟುತ್ತೀರಿ. ಹೆಚ್ಚಿನ ಖರ್ಚನ್ನು ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ಕಟ್ಟುತ್ತಾರೆ. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರ ವ್ಯಾಪಾರದಲ್ಲಿ {{ site.data.facts.esi.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇದ್ದು, ನಿಮ್ಮ ESI ವೇತನ {{ site.data.facts.esi.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇದ್ದರೆ, ಸೇರುವುದು ಕಡ್ಡಾಯ.

ಉದ್ಯೋಗದಾತರೇ? ಈ ಪುಟವನ್ನು ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಯೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳಿ.

{{ site.data.facts.tools_checked_kn }}ರಂದು ನಿಯಮಗಳನ್ನು ಪರಿಶೀಲಿಸಲಾಗಿದೆ

ESI ಎಂದರೇನು

ESI ಸಿಬ್ಬಂದಿಗಾಗಿ ಇರುವ ಸರ್ಕಾರದ ವಿಮಾ ಯೋಜನೆ. ನಿಮ್ಮ ESI ವೇತನ ತಿಂಗಳಿಗೆ {{ site.data.facts.esi.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇದ್ದರೆ (ವಿಕಲಚೇತನ ವ್ಯಕ್ತಿಗೆ {{ site.data.facts.esi.wage_ceiling_pwd_text }}) ಇದು ನಿಮಗೆ ಅನ್ವಯಿಸುತ್ತದೆ. ESI ವೇತನ ನಿಮ್ಮ ಪೂರ್ತಿ ಸಂಬಳ ಅಲ್ಲ. ಮನೆ ಬಾಡಿಗೆ ಭತ್ಯೆ (HRA), ಓವರ್‌ಟೈಮ್, ಬೋನಸ್, ಕಮಿಷನ್ ಮತ್ತು ಪ್ರಯಾಣ ಭತ್ಯೆಯನ್ನು ಸೇರಿಸುವುದಿಲ್ಲ. ಆದರೆ ನಿಮ್ಮ ESI ವೇತನ ನಿಮ್ಮ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆಯಾದ ಭಾಗವನ್ನು ನಿಮ್ಮ ESI ವೇತನಕ್ಕೆ ಸೇರಿಸಲಾಗುತ್ತದೆ.

ನಿಮ್ಮ ESI ವೇತನದ 0.75% ನೀವು ಕಟ್ಟುತ್ತೀರಿ. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು 3.25% ಕಟ್ಟುತ್ತಾರೆ. ಉದಾಹರಣೆ: ತಿಂಗಳಿಗೆ ₹18,000 ESI ವೇತನ. ನೀವು ₹135 ಕಟ್ಟುತ್ತೀರಿ. ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ₹585 ಕಟ್ಟುತ್ತಾರೆ. ನಿಮ್ಮದೇ ಮೊತ್ತವನ್ನು ನಮ್ಮ ಉಚಿತ ESI ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರದಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.

ನಿಮಗೆ ಏನು ಸಿಗುತ್ತದೆ

  • ಅನಾರೋಗ್ಯವಾದಾಗ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ.
  • ಅನಾರೋಗ್ಯದಿಂದ ಕೆಲಸ ಮಾಡಲು ಆಗದಿದ್ದಾಗ ಹಣದ ಸಹಾಯ.
  • ಹೆರಿಗೆಯ ಸಮಯದಲ್ಲಿ ಮಹಿಳೆಯರಿಗೆ ಹೆರಿಗೆ ಸಹಾಯ.
  • ಕೆಲಸದಲ್ಲಿ ಗಾಯವಾದರೆ ಸಹಾಯ: ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ಮತ್ತು ಹಣದ ಸಹಾಯ. ಕೆಲಸದಲ್ಲಾದ ಗಾಯದಿಂದ ನೀವು ಮರಣ ಹೊಂದಿದರೆ, ESI ನಿಮ್ಮ ಕುಟುಂಬಕ್ಕೂ ಸಹಾಯ ಮಾಡಬಹುದು.

ಪ್ರತಿ ಸೌಲಭ್ಯದ ನಿಯಮಗಳನ್ನು ESIC ನಿಗದಿಪಡಿಸುತ್ತದೆ. ವಿವರಗಳಿಗೆ ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರನ್ನು ಕೇಳಿ.

ನೀವು ಏಕೆ ಬೇಡ ಎನ್ನುವಂತಿಲ್ಲ

ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರ ವ್ಯಾಪಾರದಲ್ಲಿ {{ site.data.facts.esi.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇದ್ದು (ಅಥವಾ ಅದು ಕೆಲವು ಅಪಾಯಕಾರಿ ಕೆಲಸಗಳ ವ್ಯಾಪಾರವಾಗಿದ್ದರೆ), ನಿಮ್ಮ ESI ವೇತನ ತಿಂಗಳಿಗೆ {{ site.data.facts.esi.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇದ್ದಾಗ (ವಿಕಲಚೇತನ ವ್ಯಕ್ತಿಗೆ {{ site.data.facts.esi.wage_ceiling_pwd_text }}) ESI ಕಡ್ಡಾಯ. ನೀವು ಬೇಡ ಎನ್ನುವಂತಿಲ್ಲ, ಮತ್ತು ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ನಿಮ್ಮನ್ನು ಬಿಟ್ಟುಬಿಡುವಂತಿಲ್ಲ. ದಿನದ ಸಂಬಳ ತುಂಬಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ ತಮ್ಮ ಪಾಲನ್ನು ಕಟ್ಟುವುದಿಲ್ಲ, ಆದರೆ ಉದ್ಯೋಗದಾತರು ತಮ್ಮ ಪಾಲನ್ನು ಕಟ್ಟಲೇಬೇಕು.

ನಿಮ್ಮ ಸಂಬಳ {{ site.data.facts.esi.wage_ceiling_text }} ದಾಟಿದೆಯೇ? ನೀವೇ ESI ನಿಲ್ಲಿಸಬೇಡಿ. ಅದು ಯಾವಾಗ ನಿಲ್ಲಬಹುದು ಎಂದು ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ಪರಿಶೀಲಿಸಬೇಕು.

ESI ಬಳಸುವುದು ಹೇಗೆ

ESIನಲ್ಲಿರುವ ಪ್ರತಿ ಉದ್ಯೋಗಿಗೂ ಒಂದು IP ಸಂಖ್ಯೆ (ನಿಮ್ಮ ESI ಸಂಖ್ಯೆ) ಇರುತ್ತದೆ. ನೀವು ಸೇರಿದಾಗ ನಿಮ್ಮ ಉದ್ಯೋಗದಾತರು ನಿಮ್ಮನ್ನು ESIಗೆ ನೋಂದಣಿ ಮಾಡುತ್ತಾರೆ. ನಿಮ್ಮ IP ಸಂಖ್ಯೆಯನ್ನು ಕೇಳಿ.
