ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು ESIಗೆ ಸೇರಿಸುವುದು: IP ಸಂಖ್ಯೆ

ಹೊಸ ಉದ್ಯೋಗಿ ಸೇರಿದಾಗ, ಅವರನ್ನು ESIಗೆ ಸೇರಿಸಬೇಕಾಗಬಹುದು. ESIನಲ್ಲಿರುವ ಪ್ರತಿ ಉದ್ಯೋಗಿಗೂ IP ಸಂಖ್ಯೆ (ಅವರ ESI ಸಂಖ್ಯೆ) ಬೇಕು. ಯಾರನ್ನು ಸೇರಿಸಬೇಕು, IP ಸಂಖ್ಯೆ ಎಂದರೇನು ಮತ್ತು ನೀವು ಏನು ಮಾಡಬೇಕು ಎಂಬುದು ಇಲ್ಲಿದೆ.

ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು ಯಾವಾಗ ಸೇರಿಸಬೇಕು

ESI (ಉದ್ಯೋಗಿಗಳ ರಾಜ್ಯ ವಿಮೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ನೀಡುತ್ತದೆ. ಅನಾರೋಗ್ಯ, ಗಾಯ ಅಥವಾ ಹೆರಿಗೆಯಿಂದ ಕೆಲಸ ಮಾಡಲು ಆಗದಿದ್ದಾಗ ಹಣದ ಸಹಾಯವನ್ನೂ ನೀಡುತ್ತದೆ.

10 ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇರುವ ವ್ಯಾಪಾರಕ್ಕೆ ESI ಅನ್ವಯಿಸುತ್ತದೆ. ಋತುಮಾನದ ಕಾರ್ಖಾನೆಗಳಿಗೆ ESI ಅನ್ವಯಿಸುವುದಿಲ್ಲ. ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ESI ಅನ್ವಯಿಸುತ್ತದೆಯೇ ಎಂದು ಖಚಿತವಿಲ್ಲವೇ? {% include link.html path="blogs/esi-applicability-threshold" label="ನೀವು ESI ನೋಂದಣಿ ಮಾಡಬೇಕೇ?" arrow=false %} ಓದಿ.

ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ESI ಅನ್ವಯಿಸಿದರೆ, ಹೊಸ ಉದ್ಯೋಗಿಯ ESI ವೇತನ ತಿಂಗಳಿಗೆ {{ esi.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇದ್ದರೆ (ವಿಕಲಚೇತನ ವ್ಯಕ್ತಿಗೆ {{ esi.wage_ceiling_pwd_text }}) ಅವರು ESIನಲ್ಲಿ ಇರಬೇಕು.

ESI ವೇತನ ಪೂರ್ತಿ ಸಂಬಳ ಅಲ್ಲ. ESI ವೇತನದಲ್ಲಿ ಸಂಬಳದ ಕೆಲವು ಭಾಗಗಳನ್ನು ಸೇರಿಸುವುದಿಲ್ಲ, ಉದಾಹರಣೆಗೆ HRA (ಮನೆ ಬಾಡಿಗೆ ಭತ್ಯೆ) ಮತ್ತು ಓವರ್‌ಟೈಮ್. ಆದರೆ ESI ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು ESI ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

ಹಾಗಾಗಿ ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ, ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು ಅವರು ಸೇರಿದ ಕೂಡಲೇ ಸೇರಿಸಿ. ಯಾರು PF ಮತ್ತು ESIನಲ್ಲಿ ಇರಬೇಕು ಎಂದು ನಾವು ಪರಿಶೀಲಿಸುತ್ತೇವೆ. ಹಾಗಾಗಿ ನೀವು ಸರಿಯಾದವರನ್ನೇ ಸೇರಿಸುತ್ತೀರಿ. ಒಬ್ಬ ಉದ್ಯೋಗಿಯನ್ನು ನೀವೇ ಪರಿಶೀಲಿಸಲು ನಮ್ಮ {% include link.html path="esi-eligibility-checker" label="ESI ಅರ್ಹತೆ ಪರಿಶೀಲನೆ" arrow=false %} ಬಳಸಿ.

IP ಸಂಖ್ಯೆ ಎಂದರೇನು

IP (Insured Person, ವಿಮೆ ಪಡೆದ ವ್ಯಕ್ತಿ) ಸಂಖ್ಯೆ ಎಂದರೆ ಉದ್ಯೋಗಿಯ ESI ಸಂಖ್ಯೆ. ESIನಲ್ಲಿರುವ ಪ್ರತಿ ಉದ್ಯೋಗಿಗೂ ಒಂದು IP ಸಂಖ್ಯೆ ಬೇಕು.

IP ಸಂಖ್ಯೆ UANಗಿಂತ ಬೇರೆ. UAN ಎಂದರೆ ಅವರ PF ಖಾತೆ ಸಂಖ್ಯೆ. PF (ಭವಿಷ್ಯ ನಿಧಿ, EPF ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ಉಳಿತಾಯ ಮತ್ತು ಪಿಂಚಣಿ ನೀಡುತ್ತದೆ. PF ಮತ್ತು ESI ಎರಡರಲ್ಲೂ ಇರುವ ಹೊಸ ಉದ್ಯೋಗಿಗೆ ಎರಡೂ ಸಂಖ್ಯೆಗಳು ಬೇಕು. {% include link.html path="blogs/new-staff-uan-umang-face-scan" label="ಹೊಸ ಸಿಬ್ಬಂದಿ ಮತ್ತು UAN: UMANG ಮುಖದ ಸ್ಕ್ಯಾನ್, ಉದ್ಯೋಗದಾತರಿಗಾಗಿ ವಿವರಣೆ" arrow=false %} ಓದಿ.

ಕೆಲಸ ಬದಲಿಸಿದರೂ, ಉದ್ಯೋಗಿಗೆ ಜೀವನಪೂರ್ತಿ ಅದೇ IP ಸಂಖ್ಯೆ ಇರುತ್ತದೆ. ನಿಮ್ಮ ಹೊಸ ಉದ್ಯೋಗಿ ಹಿಂದಿನ ಕೆಲಸದಲ್ಲಿ ESIನಲ್ಲಿ ಇದ್ದರೇ? ಹಾಗಿದ್ದರೆ ಅವರಿಗೆ ಹೊಸ IP ಸಂಖ್ಯೆ ಬೇಕಿಲ್ಲ. ಅವರನ್ನು ಸೇರಿಸುವ ಮೊದಲು ನಮಗೆ ಕರೆ ಮಾಡಿ. ಮುಂದೆ ಏನು ಮಾಡಬೇಕು ಎಂದು ನಾವು ಹೇಳುತ್ತೇವೆ.

ESIC ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಸೇರಿಸುವುದು

ESIC (ಸರ್ಕಾರದ ESI ಇಲಾಖೆ) ESIC ಪೋರ್ಟಲ್ ಅನ್ನು ನಡೆಸುತ್ತದೆ. ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು ಈ ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ESIಗೆ ಸೇರಿಸಲಾಗುತ್ತದೆ, IP ಸಂಖ್ಯೆಯೂ ಅಲ್ಲೇ ಆಗುತ್ತದೆ.

ನಮ್ಮೊಂದಿಗೆ ಕೆಲಸ ಮಾಡುತ್ತಿದ್ದೀರಾ? ESIC ಪೋರ್ಟಲ್‌ನಲ್ಲಿ IP ಸಂಖ್ಯೆಗಳನ್ನು ನಾವು ಮಾಡಿಕೊಡುತ್ತೇವೆ. ಯಾರಾದರೂ ಹೊಸಬರು ಸೇರಿದಾಗ ನೀವು ನಮಗೆ ತಿಳಿಸಿ. ನಮಗೆ ಯಾವ ವಿವರಗಳು ಬೇಕು ಎಂದು ನಾವು ಹೇಳುತ್ತೇವೆ, ಮತ್ತು ಅವರನ್ನು ಸೇರಿಸುತ್ತೇವೆ.

ನೀವೇ ಮಾಡುತ್ತೀರಾ? ಉದ್ಯೋಗಿಯನ್ನು ನೀವು ESIC ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಸೇರಿಸುತ್ತೀರಿ.

ನಿಮ್ಮ ಹೊಸ ಉದ್ಯೋಗಿ ನಿಮಗೆ ಏನು ಕೊಡಬೇಕು ಎಂದು ಖಚಿತವಿಲ್ಲವೇ? ನಮಗೆ ಕರೆ ಮಾಡಿ. ನಮಗೆ ಯಾವ ವಿವರಗಳು ಬೇಕು ಎಂದು ನಾವು ಹೇಳುತ್ತೇವೆ.

ಅವರು ESIಗೆ ಸೇರಿದ ನಂತರ, ಹೆಚ್ಚಿನ ಉದ್ಯೋಗಿಗಳು ತಮ್ಮ ESI ವೇತನದ 0.75% ಕಟ್ಟುತ್ತಾರೆ. ನೀವು 3.25% ಕಟ್ಟುತ್ತೀರಿ. ದಿನದ ಸಂಬಳ ತುಂಬಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ ತಮ್ಮ ಪಾಲನ್ನು ಕಟ್ಟುವುದಿಲ್ಲ, ಆದರೆ ನೀವು 3.25% ಕಟ್ಟಲೇಬೇಕು. ಪ್ರತಿ ತಿಂಗಳ ESI ಅನ್ನು ಮುಂದಿನ ತಿಂಗಳ {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು. ಮೊತ್ತಗಳನ್ನು ನಮ್ಮ {% include link.html path="esi-contribution-calculator" label="ESI ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರ" arrow=false %}ದಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.

ESI ತಮಗೆ ಏನು ನೀಡುತ್ತದೆ ಎಂದು ನಿಮ್ಮ ಉದ್ಯೋಗಿ ಕೇಳುತ್ತಾರೆಯೇ? {% include link.html path="blogs/esi-benefits-for-employees" label="ಉದ್ಯೋಗಿಗಳಿಗೆ ESI ಸೌಲಭ್ಯಗಳು" arrow=false %} ಎಂಬ ನಮ್ಮ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ಅವರೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳಿ.

ಕುಟುಂಬದ ವಿವರಗಳು ಮತ್ತು e-Pehchan ಕಾರ್ಡ್

ESI ಉದ್ಯೋಗಿಯ ಕುಟುಂಬಕ್ಕೂ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ನೀಡುತ್ತದೆ. ಹಾಗಾಗಿ ನೀವು ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು ಸೇರಿಸುವಾಗ, ESIC ಅವರ ಕುಟುಂಬದ ವಿವರಗಳನ್ನು, ಮತ್ತು ಉದ್ಯೋಗಿ ಹಾಗೂ ಅವರ ಕುಟುಂಬದವರ ಆಧಾರ್ ಸಂಖ್ಯೆಗಳನ್ನು ಕೇಳುತ್ತದೆ. ನಂತರ ಉದ್ಯೋಗಿಗೆ e-Pehchan ಕಾರ್ಡ್ ಸಿಗುತ್ತದೆ. ಅದು ಅವರ ESI ಗುರುತಿನ ಚೀಟಿ. ESI ಕ್ಲಿನಿಕ್‌ಗಳು ಮತ್ತು ಆಸ್ಪತ್ರೆಗಳಲ್ಲಿ ಚಿಕಿತ್ಸೆ ಪಡೆಯಲು ಅವರು ಮತ್ತು ಅವರ ಕುಟುಂಬದವರು ಅದನ್ನು ಬಳಸುತ್ತಾರೆ.

ನಿಮ್ಮ ಹೊಸ ಉದ್ಯೋಗಿಯಿಂದ ಏನು ಕೇಳಬೇಕು ಎಂದು ಖಚಿತವಿಲ್ಲವೇ? ನಮಗೆ ಕರೆ ಮಾಡಿ.

ಈ ತಪ್ಪುಗಳನ್ನು ಮಾಡಬೇಡಿ

  • ಸೇರಿಸಲು ತಡ ಮಾಡುವುದು. ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ, ಪ್ರತಿ ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು ಅವರು ಸೇರಿದ ಕೂಡಲೇ ಸೇರಿಸಿ. ಇದು {% include link.html path="blogs/common-esi-compliance-mistakes" label="ESIನಲ್ಲಿ 7 ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು, ಮತ್ತು ಅವುಗಳನ್ನು ಸರಿಪಡಿಸುವುದು ಹೇಗೆ" arrow=false %} ಎಂಬ ಮಾರ್ಗದರ್ಶಿಯ 7ನೇ ತಪ್ಪು.
  • ಪೂರ್ತಿ ಸಂಬಳವನ್ನು ಬಳಸುವುದು. ಯಾರು ESIನಲ್ಲಿ ಇರಬೇಕು ಎಂಬುದನ್ನು ಅವರ ESI ವೇತನದಿಂದ ನಿರ್ಧರಿಸಿ, ಪೂರ್ತಿ ಸಂಬಳದಿಂದ ಅಲ್ಲ.
  • ಹಿಂದಿನ ಕೆಲಸದ ಬಗ್ಗೆ ಕೇಳದಿರುವುದು. ಪ್ರತಿ ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು, ಅವರು ಹಿಂದೆ ESIನಲ್ಲಿ ಇದ್ದರೇ ಎಂದು ಕೇಳಿ. ಇದ್ದರೆ, ಅವರನ್ನು ಸೇರಿಸುವ ಮೊದಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.
  • ಸಂಬಳದ ಬದಲಾವಣೆಗಳನ್ನು ಮರೆಯುವುದು. ಯಾರದಾದರೂ ESI ವೇತನ {{ esi.wage_ceiling_text }} ದಾಟಿದೆಯೇ? ಏನು ಮಾಡಬೇಕು ಎಂದು ತಿಳಿಯಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.
  • ಕೆಲಸ ಬಿಡುವ ಸಿಬ್ಬಂದಿಯನ್ನು ಮರೆಯುವುದು. ಸಿಬ್ಬಂದಿ ಕೆಲಸ ಬಿಟ್ಟಾಗ, ಆ ದಿನಾಂಕವನ್ನು ಗುರುತಿಸಿ.

ಹೊಸ ಸಿಬ್ಬಂದಿಯನ್ನು ಸೇರಿಸುವುದು ಪ್ರತಿ ತಿಂಗಳ ಕೆಲಸದ ಭಾಗ. {% include link.html path="blogs/pf-esi-monthly-checklist" label="PF ಮತ್ತು ESI ಮಾಸಿಕ ಪರಿಶೀಲನಾ ಪಟ್ಟಿ: 15ನೇ ತಾರೀಖಿನೊಳಗೆ ಏನು ಮಾಡಬೇಕು" arrow=false %} ಓದಿ. ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ ಈಗಷ್ಟೇ 10 ಸಿಬ್ಬಂದಿ ಆಗಿದ್ದಾರೆಯೇ? {% include link.html path="blogs/pf-esi-reached-10-or-20-staff" label="ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ ಈಗಷ್ಟೇ 10 ಅಥವಾ 20 ಸಿಬ್ಬಂದಿ ಆಗಿದ್ದಾರೆ: ಮುಂದೆ ಏನು ಮಾಡಬೇಕು" arrow=false %} ಓದಿ.

ಇದನ್ನು ನೀವೇ ಮಾಡಲು ಬಯಸುವುದಿಲ್ಲವೇ? ಪ್ರತಿ ತಿಂಗಳು ನಿಮಗಾಗಿ ನಾವು ESI ಫೈಲ್ ಮಾಡುತ್ತೇವೆ. ನೀವು {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಲು ಆಗುವಂತೆ, ಪಾವತಿ ಚೀಟಿಯನ್ನು (ಚಲನ್) ನಾವು ಸಮಯಕ್ಕೆ ಸಿದ್ಧಮಾಡುತ್ತೇವೆ. ಅಥವಾ ಹಣವನ್ನು ನಮಗೆ ಕಳುಹಿಸಿದರೆ ನಾವು ಕಟ್ಟುತ್ತೇವೆ. ನಮ್ಮ {% include link.html path="esi-consultancy-service" label="ESI ಮಾಸಿಕ ಫೈಲಿಂಗ್ ಸೇವೆ" arrow=false %} ನೋಡಿ.
