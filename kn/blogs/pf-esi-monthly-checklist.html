PF ಮತ್ತು ESI ಮಾಸಿಕ ಪರಿಶೀಲನಾ ಪಟ್ಟಿ: {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಏನು ಮಾಡಬೇಕು

PF ಮತ್ತು ESI ಅನ್ನು ಪ್ರತಿ ತಿಂಗಳು, ಮುಂದಿನ ತಿಂಗಳ {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು. ಪ್ರತಿ ತಿಂಗಳು ಏನು ಮಾಡಬೇಕು ಎಂದು ಈ ಪಟ್ಟಿ ಹಂತ ಹಂತವಾಗಿ ತೋರಿಸುತ್ತದೆ. ಹೀಗೆ ನೀವು ಸಮಯಕ್ಕೆ ಸರಿಯಾಗಿ ಕಟ್ಟಬಹುದು.

ತಿಂಗಳು ಮುಗಿಯುವ ಮೊದಲು: ಸಂಬಳ, ಹೊಸ ಸಿಬ್ಬಂದಿ ಮತ್ತು ಕೆಲಸ ಬಿಟ್ಟವರು

PF (ಭವಿಷ್ಯ ನಿಧಿ, EPF ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ಉಳಿತಾಯ ಮತ್ತು ಪಿಂಚಣಿ ನೀಡುತ್ತದೆ. ESI (ಉದ್ಯೋಗಿಗಳ ರಾಜ್ಯ ವಿಮೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ನೀಡುತ್ತದೆ. ಅನಾರೋಗ್ಯ, ಗಾಯ ಅಥವಾ ಹೆರಿಗೆಯಿಂದ ಕೆಲಸ ಮಾಡಲು ಆಗದಿದ್ದಾಗ ಹಣದ ಸಹಾಯವನ್ನೂ ನೀಡುತ್ತದೆ.

ಎರಡನ್ನೂ ಪ್ರತಿ ತಿಂಗಳ ಸಂಬಳದಿಂದ ಲೆಕ್ಕ ಹಾಕುತ್ತಾರೆ. ಹಾಗಾಗಿ ತಿಂಗಳ ಕೆಲಸ ನಿಮ್ಮ ಸಂಬಳದ ಶೀಟ್‌ನಿಂದ ಶುರುವಾಗುತ್ತದೆ.

  • ಸಂಬಳದ ಶೀಟ್ ಪೂರ್ತಿ ಮಾಡಿ. ಪ್ರತಿ ಉದ್ಯೋಗಿ ಆ ತಿಂಗಳು ಕೆಲಸ ಮಾಡಿದ ದಿನಗಳು ಮತ್ತು ಸಂಬಳವನ್ನು ಬರೆಯಿರಿ.
  • ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ, ಹೊಸ ಸಿಬ್ಬಂದಿಯನ್ನು PF ಮತ್ತು ESIಗೆ ಸೇರಿಸಿ. ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದೀರಾ? ಯಾರು PF ಮತ್ತು ESIನಲ್ಲಿ ಇರಬೇಕು ಎಂದು ನಾವು ಪರಿಶೀಲಿಸುತ್ತೇವೆ.
  • UAN ಇಲ್ಲದ ಹೊಸ ಸಿಬ್ಬಂದಿ. UAN ಎಂದರೆ ಅವರ PF ಖಾತೆ ಸಂಖ್ಯೆ. ಹೊಸ ಸಿಬ್ಬಂದಿ UMANG ಆ್ಯಪ್‌ನಲ್ಲಿ ಬೇಗ ಮುಗಿಯುವ ಮುಖದ ಸ್ಕ್ಯಾನ್ ಮೂಲಕ UAN ಪಡೆಯುತ್ತಾರೆ. ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದೀರಾ? ನಾವು ಅವರಿಗೆ ಮಾರ್ಗದರ್ಶನ ನೀಡುತ್ತೇವೆ. {% include link.html path="blogs/new-staff-uan-umang-face-scan" label="ಹೊಸ ಸಿಬ್ಬಂದಿ ಮತ್ತು UAN: UMANG ಮುಖದ ಸ್ಕ್ಯಾನ್" arrow=false %} ಓದಿ.
  • ಹೊಸ ಸಿಬ್ಬಂದಿಗೆ ESI ಸಂಖ್ಯೆ ಬೇಕು. ESIನಲ್ಲಿ ಇರುವ ಪ್ರತಿ ಉದ್ಯೋಗಿಗೆ IP ಸಂಖ್ಯೆ (ಅವರ ESI ಸಂಖ್ಯೆ) ಬೇಕು. ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದೀರಾ? ನಾವು ESIC ಪೋರ್ಟಲ್‌ನಲ್ಲಿ IP ಸಂಖ್ಯೆ ಮಾಡಿಕೊಡುತ್ತೇವೆ. ESIC ಎಂದರೆ ಸರ್ಕಾರದ ESI ಇಲಾಖೆ. {% include link.html path="blogs/esi-ip-number-new-employee" label="ಹೊಸ ಉದ್ಯೋಗಿಯನ್ನು ESIಗೆ ಸೇರಿಸುವುದು: IP ಸಂಖ್ಯೆ" arrow=false %} ಓದಿ.
  • ಕೆಲಸ ಬಿಟ್ಟವರು ಬಿಟ್ಟ ದಿನಾಂಕವನ್ನು ನಮೂದಿಸಿ. ಇದನ್ನು PF ಮತ್ತು ESI ಎರಡರಲ್ಲೂ ಮಾಡಿ. ಆಗ ಅವರ ದಾಖಲೆಗಳು ಸರಿಯಾಗಿರುತ್ತವೆ. {% include link.html path="blogs/staff-leaving-pf-esi-exit-date" label="ಸಿಬ್ಬಂದಿ ಕೆಲಸ ಬಿಟ್ಟಾಗ" arrow=false %} ಓದಿ.
  • ಸಂಬಳದ ಬದಲಾವಣೆಗಳನ್ನು ಪರಿಶೀಲಿಸಿ. PF ವೇತನ ಮಿತಿ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_text }} PF ವೇತನ (ಇದನ್ನು ಕೆಳಗೆ ವಿವರಿಸಲಾಗಿದೆ). ESI ವೇತನ ಮಿತಿ ತಿಂಗಳಿಗೆ {{ esi.wage_ceiling_text }} ESI ವೇತನ. ಯಾರದಾದರೂ ಸಂಬಳ ಒಂದು ಮಿತಿಯನ್ನು ದಾಟಿದರೆ, ಏನು ಮಾಡಬೇಕು ಎಂದು ತಿಳಿಯಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

ESI ವೇತನದಲ್ಲಿ ಸಂಬಳದ ಕೆಲವು ಭಾಗಗಳು ಸೇರುವುದಿಲ್ಲ. ಉದಾಹರಣೆಗೆ HRA (ಮನೆ ಬಾಡಿಗೆ ಭತ್ಯೆ) ಮತ್ತು ಓವರ್‌ಟೈಮ್. ಆದರೆ ESI ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು ESI ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

ECR ಮತ್ತು ESI ವಂತಿಗೆಯನ್ನು ಸಿದ್ಧಮಾಡಿ

PFಗೆ, ನೀವು ECR ಸಿದ್ಧಮಾಡುತ್ತೀರಿ. ECR ಎಂದರೆ ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ಸಂಬಳ ಮತ್ತು PFನ ಮಾಸಿಕ ಪಟ್ಟಿ, PF ಇಲಾಖೆಗೆ ಕಳುಹಿಸುವುದು.

PF ಅನ್ನು PF ವೇತನದ ಮೇಲೆ ಲೆಕ್ಕ ಹಾಕುತ್ತಾರೆ. PF ವೇತನ ಎಂದರೆ ಮೂಲ ವೇತನ ಮತ್ತು DA (ತುಟ್ಟಿ ಭತ್ಯೆ), ಪೂರ್ತಿ ಸಂಬಳ ಅಲ್ಲ. ವಿಶೇಷ ಭತ್ಯೆಯಂತಹ ಬೇರೆ ಭತ್ಯೆಗಳು ಸಹ PF ವೇತನಕ್ಕೆ ಲೆಕ್ಕಕ್ಕೆ ಬರಬಹುದು. ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ. ಆದರೆ PF ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು PF ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು. ಉದ್ಯೋಗಿ ತಮ್ಮ PF ವೇತನದ 12% ಕಟ್ಟುತ್ತಾರೆ. ನೀವು 12% ಕಟ್ಟುತ್ತೀರಿ.

ಅನೇಕ ವ್ಯಾಪಾರಗಳು ECR ಅನ್ನು ಎಕ್ಸೆಲ್ ಶೀಟ್‌ನಲ್ಲಿ ಇಡುತ್ತವೆ. ನಮ್ಮ ಉಚಿತ {% include link.html path="epf-excel-to-text-converter" label="EPF ಎಕ್ಸೆಲ್‌ನಿಂದ ಟೆಕ್ಸ್ಟ್ ಪರಿವರ್ತಕ" arrow=false %} ಸಾಧನ ECR ಫೈಲ್ ಸಿದ್ಧಮಾಡಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ. ಫೈಲ್ ಸ್ವೀಕಾರವಾಗದಿದ್ದರೆ, {% include link.html path="blogs/common-ecr-upload-errors-and-fixes" label="ECR ಅಪ್‌ಲೋಡ್‌ನಲ್ಲಿ ಸಾಮಾನ್ಯ ದೋಷಗಳು ಮತ್ತು ಅವುಗಳನ್ನು ಸರಿಪಡಿಸುವುದು ಹೇಗೆ" arrow=false %} ಓದಿ.

ESIಗೆ, ESIನಲ್ಲಿ ಇರುವ ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ESI ವಂತಿಗೆಯನ್ನು ನೀವು ಲೆಕ್ಕ ಹಾಕುತ್ತೀರಿ. ಇದನ್ನು ESI ವೇತನದ ಮೇಲೆ ಲೆಕ್ಕ ಹಾಕುತ್ತಾರೆ. ಹೆಚ್ಚಿನ ಉದ್ಯೋಗಿಗಳು ತಮ್ಮ ESI ವೇತನದ 0.75% ಕಟ್ಟುತ್ತಾರೆ. ನೀವು 3.25% ಕಟ್ಟುತ್ತೀರಿ. ಒಟ್ಟು 4%. ದಿನದ ಸಂಬಳ ತುಂಬಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ ತಮ್ಮ ಪಾಲನ್ನು ಕಟ್ಟುವುದಿಲ್ಲ. ಆದರೆ ನೀವು 3.25% ಕಟ್ಟಲೇಬೇಕು.

ಪಾವತಿ ಚೀಟಿಗಳನ್ನು (ಚಲನ್) ಸಿದ್ಧಮಾಡಿ

ಚಲನ್ ಎಂದರೆ PF/ESI ಪಾವತಿ ಚೀಟಿ. ಆ ತಿಂಗಳು ನೀವು ಎಷ್ಟು ಕಟ್ಟಬೇಕು ಎಂದು ಅದು ತೋರಿಸುತ್ತದೆ. PFಗೆ ಒಂದು ಚಲನ್, ESIಗೆ ಒಂದು ಚಲನ್ ಇರುತ್ತದೆ.

ಕಟ್ಟುವ ಮೊದಲು, ಚಲನ್‌ನ ಮೊತ್ತವನ್ನು ನಿಮ್ಮ ಸಂಬಳದ ಶೀಟ್ ಜೊತೆ ಹೋಲಿಸಿ ನೋಡಿ. ಯಾವುದಾದರೂ ಅಂಕಿ ತಪ್ಪು ಎನಿಸಿದರೆ, ಕಟ್ಟಿದ ನಂತರ ಅಲ್ಲ, ಕಟ್ಟುವ ಮೊದಲೇ ಸರಿಪಡಿಸಿ.

{{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಿ

PF ಅನ್ನು ಮುಂದಿನ ತಿಂಗಳ {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು. ESI ಅನ್ನು ಕೂಡ ಮುಂದಿನ ತಿಂಗಳ {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು. ಉದಾಹರಣೆಗೆ, ಅಕ್ಟೋಬರ್ ಸಂಬಳದ PF ಮತ್ತು ESI ಅನ್ನು 15 ನವೆಂಬರ್‌ನೊಳಗೆ ಕಟ್ಟಬೇಕು.

ಕೆಲವು ದಿನ ಮೊದಲೇ ಕಟ್ಟಲು ಯೋಜಿಸಿ. ಆಗ ಕೊನೆಯ ದಿನ ಬ್ಯಾಂಕ್ ಅಥವಾ ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ ಸಮಸ್ಯೆ ಬಂದರೂ ನೀವು ತಡವಾಗುವುದಿಲ್ಲ.

ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದೀರಾ? ನೀವು {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಲು ಆಗುವಂತೆ, ಪಾವತಿ ಚೀಟಿಯನ್ನು (ಚಲನ್) ನಾವು ಸಮಯಕ್ಕೆ ಸಿದ್ಧಮಾಡುತ್ತೇವೆ. ಅಥವಾ ಹಣವನ್ನು ನಮಗೆ ಕಳುಹಿಸಿ, ನಾವು ಕಟ್ಟುತ್ತೇವೆ.

ತಡವಾಗಿ ಕಟ್ಟಿದರೆ ಹೆಚ್ಚುವರಿ ಹಣ ಕಟ್ಟಬೇಕಾಗಬಹುದು. {% include link.html path="blogs/epf-late-payment-penalty" label="PF ತಡವಾಗಿ ಕಟ್ಟಿದರೆ ಏನಾಗುತ್ತದೆ" arrow=false %} ಮತ್ತು {% include link.html path="blogs/esi-late-payment-penalty" label="ESI ತಡವಾಗಿ ಕಟ್ಟಿದರೆ ಏನಾಗುತ್ತದೆ" arrow=false %} ಓದಿ. ಅಂದಾಜು ನೋಡಲು ನಮ್ಮ {% include link.html path="epf-penalty-calculator" label="PF ದಂಡ ಲೆಕ್ಕಾಚಾರ" arrow=false %} ಅಥವಾ {% include link.html path="esi-penalty-calculator" label="ESI ದಂಡ ಲೆಕ್ಕಾಚಾರ" arrow=false %} ಸಾಧನ ಬಳಸಿ.

ರಸೀದಿಗಳನ್ನು ಜೋಪಾನವಾಗಿ ಇಡಿ

ಕಟ್ಟಿದ ನಂತರ, ಇವುಗಳ ಪ್ರತಿಯನ್ನು ಇಡಿ:

  • ECR ಮತ್ತು PF ಚಲನ್
  • ESI ವಂತಿಗೆಯ ವಿವರ ಮತ್ತು ESI ಚಲನ್
  • ಪ್ರತಿಯೊಂದರ ಪಾವತಿ ರಸೀದಿ
  • ಆ ತಿಂಗಳ ಸಂಬಳದ ಶೀಟ್

ಇವನ್ನು ತಿಂಗಳುವಾರು ಒಟ್ಟಿಗೆ ಇಡಿ. {% include link.html path="blogs/pf-inspection-guide" label="PF ತಪಾಸಣೆ" arrow=false %} ಅಥವಾ {% include link.html path="blogs/esi-inspection-guide" label="ESI ತಪಾಸಣೆಯಲ್ಲಿ" arrow=false %} ನಿಮ್ಮ ದಾಖಲೆಗಳನ್ನು ಕೇಳಬಹುದು. ನೀವು ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದರೆ, ಪ್ರತಿ ತಿಂಗಳು ರಸೀದಿ ಮತ್ತು ಚಲನ್‌ಗಳನ್ನು ನಿಮಗೆ ಇಮೇಲ್ ಮಾಡುತ್ತೇವೆ.

ಈ ತಿಂಗಳು: ಬದಲಾವಣೆಗಳು ಮತ್ತು ನೆನಪುಗಳು (ಅಕ್ಟೋಬರ್ 2026)

ಈ ಭಾಗವನ್ನು ನಾವು ಪ್ರತಿ ತಿಂಗಳು ಬದಲಿಸುತ್ತೇವೆ.

  • ಸೆಪ್ಟೆಂಬರ್ ಸಂಬಳ: ಸೆಪ್ಟೆಂಬರ್ 2026ರ ಸಂಬಳದ PF ಕಟ್ಟುವ ಕೊನೆಯ ದಿನಾಂಕವನ್ನು EPFO (ಸರ್ಕಾರದ PF ಇಲಾಖೆ) 31 ಅಕ್ಟೋಬರ್ 2026ಕ್ಕೆ ಮುಂದೂಡಿದೆ. ಇದು ಸೆಪ್ಟೆಂಬರ್‌ಗೆ ಮಾತ್ರ. ಸೆಪ್ಟೆಂಬರ್ ಸಂಬಳದ ESI ಅನ್ನು 15 ಅಕ್ಟೋಬರ್ 2026ರೊಳಗೆ ಕಟ್ಟಬೇಕಿತ್ತು.
  • ಅಕ್ಟೋಬರ್ ಸಂಬಳ: ಅಕ್ಟೋಬರ್ ಸಂಬಳದ PF ಮತ್ತು ESI ಅನ್ನು 15 ನವೆಂಬರ್ 2026ರೊಳಗೆ ಕಟ್ಟಬೇಕು.
  • ಹೊಸ PF ವೇತನ ಮಿತಿ: {{ epf.wage_ceiling_from_kn }}ರಂದು PF ವೇತನ ಮಿತಿ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_old_text }}ದಿಂದ {{ epf.wage_ceiling_text }}ಕ್ಕೆ ಏರಿತು. {{ epf.wage_ceiling_text }} ಮಿತಿಯ ಮೊದಲ ಪೂರ್ತಿ ತಿಂಗಳು ಅಕ್ಟೋಬರ್. ನಿಮ್ಮ ಯಾವ ಸಿಬ್ಬಂದಿ ಈಗ PFನಲ್ಲಿ ಇರಬೇಕು ಎಂದು ಪರಿಶೀಲಿಸಿ. {% include link.html path="blogs/pf-wage-limit-25000" label="PF ವೇತನ ಮಿತಿ ಈಗ ₹25,000" arrow=false %} ಓದಿ.
  • ಸೆಪ್ಟೆಂಬರ್ 2026ರ ಸಂಬಳ ಮತ್ತು ಹೊಸ ಮಿತಿ: ಹೊಸ ಮಿತಿಯ ಬಗ್ಗೆ EPFOನ FAQಗಳ (ಸಾಮಾನ್ಯ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಗಳು) ಪ್ರಕಾರ ಸೆಪ್ಟೆಂಬರ್ 2026ಕ್ಕೆ ಒಂದೇ ECR ಕಳುಹಿಸಬೇಕು. 1ರಿಂದ 16 ಸೆಪ್ಟೆಂಬರ್‌ವರೆಗೆ ಹಳೆಯ {{ epf.wage_ceiling_old_text }} ಮಿತಿಯಲ್ಲಿ, 17ರಿಂದ 30 ಸೆಪ್ಟೆಂಬರ್‌ವರೆಗೆ ಹೊಸ {{ epf.wage_ceiling_text }} ಮಿತಿಯಲ್ಲಿ PF ಲೆಕ್ಕ ಹಾಕಿ. ಹೊಸ ಮಿತಿಯಿಂದಾಗಿ ಮಾತ್ರ PFಗೆ ಸೇರುವ ಸಿಬ್ಬಂದಿಯ PF 17 ಸೆಪ್ಟೆಂಬರ್‌ನಿಂದ ಶುರುವಾಗುತ್ತದೆ. ಹೊಸ {{ epf.wage_ceiling_text }} ಮಿತಿ EPS (ಪಿಂಚಣಿ) ವೇತನಕ್ಕೂ ಅನ್ವಯಿಸುತ್ತದೆ ಎಂದು FAQಗಳು ಹೇಳುತ್ತವೆ. ಈಗಾಗಲೇ {{ epf.wage_ceiling_text }}ಕ್ಕಿಂತ ಹೆಚ್ಚಿನ ವೇತನದ ಮೇಲೆ PF ಕಟ್ಟುತ್ತಿರುವ ಸಿಬ್ಬಂದಿ ಅದನ್ನು ಇಳಿಸಬೇಕಿಲ್ಲ. ನಮಗೆ ಕರೆ ಮಾಡಿ, ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ಏನು ಮಾಡಬೇಕು ಎಂದು ನಾವು ಹೇಳುತ್ತೇವೆ.
  • ಹೊಸ ESI ವಂತಿಗೆ ಅವಧಿ: ಅಕ್ಟೋಬರ್‌ನಲ್ಲಿ ಹೊಸ ESI ವಂತಿಗೆ ಅವಧಿ ಶುರುವಾಯಿತು. ಇದು ಅಕ್ಟೋಬರ್‌ನಿಂದ ಮಾರ್ಚ್‌ವರೆಗೆ ಇರುತ್ತದೆ. ಆದರೂ ESI ಅನ್ನು ಪ್ರತಿ ತಿಂಗಳು ಕಟ್ಟಬೇಕು.
