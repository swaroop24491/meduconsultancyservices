ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ ಈಗಷ್ಟೇ 10 ಅಥವಾ 20 ಸಿಬ್ಬಂದಿ ಆಗಿದ್ದಾರೆ: ಮುಂದೆ ಏನು ಮಾಡಬೇಕು

ನಿಮ್ಮ ವ್ಯಾಪಾರ ಬೆಳೆಯುತ್ತಿದೆ. 10 ಅಥವಾ 20 ಸಿಬ್ಬಂದಿ ಆದಾಗ, PF ಮತ್ತು ESI ಈಗ ನಿಮಗೆ ಅನ್ವಯಿಸಬಹುದು. ಮುಂದಿನ ಹಂತಗಳು ಇಲ್ಲಿವೆ: ಪರಿಶೀಲಿಸಿ, ನೋಂದಣಿ ಮಾಡಿ, ಸಿಬ್ಬಂದಿಯನ್ನು ಸೇರಿಸಿ ಮತ್ತು ಪ್ರತಿ ತಿಂಗಳು ಕಟ್ಟಿ.

ಕೊನೆಯದಾಗಿ ಬದಲಾಯಿಸಿದ ದಿನಾಂಕ: {{ page.last_modified | date: "%-d" }} {{ t.months[month] }} {{ page.last_modified | date: "%Y" }} · {{ site.data.facts.tools_checked_kn }}ರಂದು ನಿಯಮಗಳನ್ನು ಪರಿಶೀಲಿಸಲಾಗಿದೆ

ಮೊದಲು, PF ಮತ್ತು ESI ಅನ್ವಯಿಸುತ್ತದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ

PF (ಭವಿಷ್ಯ ನಿಧಿ, EPF ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ಉಳಿತಾಯ ಮತ್ತು ಪಿಂಚಣಿ ನೀಡುತ್ತದೆ. ESI (ಉದ್ಯೋಗಿಗಳ ರಾಜ್ಯ ವಿಮೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ನೀಡುತ್ತದೆ. ಅನಾರೋಗ್ಯ, ಗಾಯ ಅಥವಾ ಹೆರಿಗೆಯಿಂದ ಕೆಲಸ ಮಾಡಲು ಆಗದಿದ್ದಾಗ ಹಣದ ಸಹಾಯವನ್ನೂ ನೀಡುತ್ತದೆ.

  • 10 ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ: ESI ಅನ್ವಯಿಸುತ್ತದೆ. ಋತುಮಾನದ ಕಾರ್ಖಾನೆಗಳಿಗೆ ESI ಅನ್ವಯಿಸುವುದಿಲ್ಲ.
  • 20 ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ: ಯಾವುದೇ ಉದ್ಯಮವಾಗಿದ್ದರೂ PF ಅನ್ವಯಿಸುತ್ತದೆ.

ನಿಮ್ಮ ಎಲ್ಲ ಸಿಬ್ಬಂದಿಯನ್ನು ಎಣಿಸಿ: ತಾತ್ಕಾಲಿಕ ಮತ್ತು ದಿನಗೂಲಿ ಸಿಬ್ಬಂದಿ ಹಾಗೂ ಗುತ್ತಿಗೆದಾರರು ಕಳುಹಿಸುವ ಸಿಬ್ಬಂದಿಯೂ ಸೇರಿ. ಯಾರನ್ನು ಎಣಿಸಬೇಕು ಎಂಬ ಪೂರ್ತಿ ನಿಯಮಗಳಿಗೆ {% include link.html path="blogs/epf-applicability-threshold" label="PF: ಯಾರು ನೋಂದಣಿ ಮಾಡಬೇಕು" arrow=false %} ಮತ್ತು {% include link.html path="blogs/esi-applicability-threshold" label="ESI: ಯಾರು ನೋಂದಣಿ ಮಾಡಬೇಕು" arrow=false %} ಓದಿ.

ಅಥವಾ ನಮ್ಮ ಉಚಿತ {% include link.html path="epf-eligibility-checker" label="PF ಅರ್ಹತೆ ಪರಿಶೀಲನೆ" arrow=false %} ಮತ್ತು {% include link.html path="esi-eligibility-checker" label="ESI ಅರ್ಹತೆ ಪರಿಶೀಲನೆ" arrow=false %} ಸಾಧನಗಳಲ್ಲಿ ನಿಮ್ಮ ವ್ಯಾಪಾರವನ್ನು ಪರಿಶೀಲಿಸಿ.

ನಿಮ್ಮ ವ್ಯಾಪಾರವನ್ನು ನೋಂದಣಿ ಮಾಡಿ

PF ಅಥವಾ ESI ನಿಮಗೆ ಅನ್ವಯಿಸಿದ ಕೂಡಲೇ ನೋಂದಣಿ ಮಾಡಿ.

  • PF: EPFOನಲ್ಲಿ (ಸರ್ಕಾರದ PF ಇಲಾಖೆ) ನಿಮ್ಮ ವ್ಯಾಪಾರವನ್ನು ನಾವು ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ.
  • ESI: ESICಯಲ್ಲಿ (ಸರ್ಕಾರದ ESI ಇಲಾಖೆ) ನಿಮ್ಮ ವ್ಯಾಪಾರವನ್ನು ನಾವು ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ.

ನಮಗೆ ಯಾವ ದಾಖಲೆಗಳು ಬೇಕು ಎಂದು ನೀವು ಕರೆ ಮಾಡಿದಾಗ ಹೇಳುತ್ತೇವೆ. ಈ ಪಟ್ಟಿ ನಿಮ್ಮ ವ್ಯಾಪಾರದ ಬಗೆಯನ್ನು ಅವಲಂಬಿಸಿದೆ. ನಿಮ್ಮ ಎಲ್ಲ ದಾಖಲೆಗಳು ನಮಗೆ ಸಿಕ್ಕ ನಂತರ, ಕೆಲವೇ ಗಂಟೆಗಳಲ್ಲಿ ಮುಗಿಯುತ್ತದೆ.

ನಾವು ಫೋನ್ ಮತ್ತು ಇಮೇಲ್ ಮೂಲಕ ಕೆಲಸ ಮಾಡುತ್ತೇವೆ. ಮಂಗಳೂರು ಮತ್ತು ಬೆಂಗಳೂರಿನಲ್ಲಿ, ಅಗತ್ಯವಿದ್ದರೆ ನಾವು ನಿಮ್ಮಲ್ಲಿಗೆ ಬರಬಹುದು. {% include link.html path="pf-registration" label="PF ನೋಂದಣಿ" arrow=false %} ಮತ್ತು {% include link.html path="esi-registration" label="ESI ನೋಂದಣಿ" arrow=false %} ನೋಡಿ.

ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಯನ್ನು ಸೇರಿಸಿ (UAN ಮತ್ತು IP ಸಂಖ್ಯೆ)

ನೋಂದಣಿಯ ನಂತರ, ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ, ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಯನ್ನು PF ಮತ್ತು ESIಗೆ ಸೇರಿಸಲಾಗುತ್ತದೆ. ಯಾರು PF ಮತ್ತು ESIನಲ್ಲಿ ಇರಬೇಕು ಎಂದು ನಾವು ಪರಿಶೀಲಿಸುತ್ತೇವೆ.

PF: PF ವೇತನ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ PFನಲ್ಲಿ ಇರಬೇಕು. PF ವೇತನ ಎಂದರೆ ಮೂಲ ವೇತನ ಮತ್ತು DA (ತುಟ್ಟಿ ಭತ್ಯೆ), ಪೂರ್ತಿ ಸಂಬಳ ಅಲ್ಲ. PF ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು PF ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

PF ವೇತನ {{ epf.wage_ceiling_text }} ದಾಟಿರುವ ಸಿಬ್ಬಂದಿ:

  • ಈಗಾಗಲೇ PFನಲ್ಲಿ ಇರುವವರು: ಅವರು PFನಲ್ಲೇ ಉಳಿಯುತ್ತಾರೆ.
  • PF ವೇತನ {{ epf.wage_ceiling_text }} ದಾಟಿರುವ, ಹಿಂದೆಂದೂ PFನಲ್ಲಿ ಇರದ ಹೊಸದಾಗಿ ಸೇರುವವರು: ನೀವು ಮತ್ತು ಅವರು ಇಬ್ಬರೂ ಲಿಖಿತವಾಗಿ ಒಪ್ಪಿದರೆ PFಗೆ ಸೇರಬಹುದು.
  • ಹಿಂದಿನ ಕೆಲಸದಲ್ಲಿ PFನಲ್ಲಿ ಇದ್ದರೇ? ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

ಇನ್ನಷ್ಟು ತಿಳಿಯಲು {% include link.html path="blogs/pf-wage-limit-25000" label="PF ವೇತನ ಮಿತಿ ಈಗ ₹25,000" arrow=false %} ಓದಿ.

ESI: ESI ವೇತನ ತಿಂಗಳಿಗೆ {{ esi.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ (ವಿಕಲಚೇತನ ವ್ಯಕ್ತಿಗೆ {{ esi.wage_ceiling_pwd_text }}) ESIನಲ್ಲಿ ಇರಬೇಕು. ESI ವೇತನದಲ್ಲಿ ಸಂಬಳದ ಕೆಲವು ಭಾಗಗಳನ್ನು ಸೇರಿಸುವುದಿಲ್ಲ, ಉದಾಹರಣೆಗೆ HRA (ಮನೆ ಬಾಡಿಗೆ ಭತ್ಯೆ) ಮತ್ತು ಓವರ್‌ಟೈಮ್. ESI ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು ESI ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

PFನಲ್ಲಿ ಇರುವ ಪ್ರತಿ ಉದ್ಯೋಗಿಗೆ UAN (ಅವರ PF ಖಾತೆ ಸಂಖ್ಯೆ) ಬೇಕು. ಹೊಸ ಸಿಬ್ಬಂದಿ UMANG ಆ್ಯಪ್‌ನಲ್ಲಿ ಬೇಗ ಮುಗಿಯುವ ಮುಖದ ಸ್ಕ್ಯಾನ್ ಮೂಲಕ UAN ಪಡೆಯುತ್ತಾರೆ. ನಾವು ಅವರಿಗೆ ಮಾರ್ಗದರ್ಶನ ನೀಡುತ್ತೇವೆ.

ESIನಲ್ಲಿ ಇರುವ ಪ್ರತಿ ಉದ್ಯೋಗಿಗೆ IP ಸಂಖ್ಯೆ (ಅವರ ESI ಸಂಖ್ಯೆ) ಬೇಕು. ESIC ಪೋರ್ಟಲ್‌ನಲ್ಲಿ IP ಸಂಖ್ಯೆಗಳನ್ನು ನಾವು ಮಾಡಿಕೊಡುತ್ತೇವೆ.

ಮುಂದೆ ಯಾರಾದರೂ ಹೊಸದಾಗಿ ಸೇರಿದಾಗ, ಯಾರು PF ಮತ್ತು ESIನಲ್ಲಿ ಇರಬೇಕು ಎಂದು ನಾವು ಮತ್ತೆ ಪರಿಶೀಲಿಸುತ್ತೇವೆ. ಸಿಬ್ಬಂದಿ ಕೆಲಸ ಬಿಟ್ಟಾಗ, ಆ ದಿನಾಂಕವನ್ನು ಗುರುತಿಸಿ.

ಪ್ರತಿ ತಿಂಗಳು {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಿ

PF ಮತ್ತು ESI ಅನ್ನು ಪ್ರತಿ ತಿಂಗಳು, ಮುಂದಿನ ತಿಂಗಳ {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು. ಉದಾಹರಣೆಗೆ, ಅಕ್ಟೋಬರ್ ಸಂಬಳದ PF ಮತ್ತು ESI ಅನ್ನು 15 ನವೆಂಬರ್‌ನೊಳಗೆ ಕಟ್ಟಬೇಕು.

  • PF: ಉದ್ಯೋಗಿ ತಮ್ಮ PF ವೇತನದ 12% ಕಟ್ಟುತ್ತಾರೆ. ನೀವು 12% ಕಟ್ಟುತ್ತೀರಿ. ಅದು ಅವರ PF ಉಳಿತಾಯ ಮತ್ತು ಪಿಂಚಣಿ ನಡುವೆ ಹಂಚಿಕೆಯಾಗುತ್ತದೆ.
  • ESI: ಹೆಚ್ಚಿನ ಉದ್ಯೋಗಿಗಳು ತಮ್ಮ ESI ವೇತನದ 0.75% ಕಟ್ಟುತ್ತಾರೆ. ನೀವು 3.25% ಕಟ್ಟುತ್ತೀರಿ. ದಿನದ ಸಂಬಳ ತುಂಬಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ ತಮ್ಮ ಪಾಲನ್ನು ಕಟ್ಟುವುದಿಲ್ಲ, ಆದರೆ ನೀವು 3.25% ಕಟ್ಟಲೇಬೇಕು.

ನಮ್ಮ ಉಚಿತ {% include link.html path="epf-contribution-calculator" label="PF ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರ" arrow=false %} ಮತ್ತು {% include link.html path="esi-contribution-calculator" label="ESI ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರ" arrow=false %} ಸಾಧನಗಳಲ್ಲಿ ಮೊತ್ತವನ್ನು ಪರಿಶೀಲಿಸಿ.

ಪ್ರತಿ ತಿಂಗಳು ನಾವು ECR (ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ಸಂಬಳ ಮತ್ತು PFನ ಮಾಸಿಕ ಪಟ್ಟಿ, PF ಇಲಾಖೆಗೆ ಕಳುಹಿಸುವುದು) ಮತ್ತು ನಿಮ್ಮ ಮಾಸಿಕ ESI ವಿವರಗಳನ್ನು ಫೈಲ್ ಮಾಡುತ್ತೇವೆ. ನೀವು {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಲು ಆಗುವಂತೆ, ಪಾವತಿ ಚೀಟಿಯನ್ನು (ಚಲನ್) ನಾವು ಸಮಯಕ್ಕೆ ಸಿದ್ಧಮಾಡುತ್ತೇವೆ. ಅಥವಾ ಹಣವನ್ನು ನಮಗೆ ಕಳುಹಿಸಿ, ನಾವು ಕಟ್ಟುತ್ತೇವೆ.

ಪ್ರತಿ ತಿಂಗಳ ಪೂರ್ತಿ ಕೆಲಸಕ್ಕೆ ನಮ್ಮ {% include link.html path="blogs/pf-esi-monthly-checklist" label="PF ಮತ್ತು ESI ಮಾಸಿಕ ಪರಿಶೀಲನಾ ಪಟ್ಟಿ" arrow=false %} ಓದಿ.

ತಡವಾಗಿ ನೋಂದಣಿ ಮಾಡಿದ್ದರೆ

ಕೆಲವು ಸಮಯದ ಹಿಂದೆಯೇ 10 ಅಥವಾ 20 ಸಿಬ್ಬಂದಿ ಆಗಿದ್ದರೂ ನೋಂದಣಿ ಮಾಡಿಲ್ಲವೇ? ಅನ್ವಯಿಸಿದ ಕೂಡಲೇ ನೋಂದಣಿ ಮಾಡಿ. ನಿಮ್ಮ ವಿಷಯವನ್ನು ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ. ನಾವು ನಿಮ್ಮ ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ, ನಂತರ ಪ್ರತಿ ತಿಂಗಳು ಸಮಯಕ್ಕೆ ಸರಿಯಾಗಿ ಫೈಲ್ ಮಾಡುತ್ತೇವೆ.

ನಾವು ಹೇಗೆ ಸಹಾಯ ಮಾಡುತ್ತೇವೆ

ನಮಗೆ ಕರೆ ಮಾಡಿ. PF ಮತ್ತು ESI ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ಅನ್ವಯಿಸುತ್ತದೆಯೇ ಎಂದು ನಾವು ಹೇಳುತ್ತೇವೆ. ನಂತರ:

  1. ನಿಮ್ಮ ವ್ಯಾಪಾರವನ್ನು ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ: PF, ESI ಅಥವಾ ಎರಡಕ್ಕೂ.
  2. ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಯನ್ನು ಸೇರಿಸುತ್ತೇವೆ, ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ.
  3. ಪ್ರತಿ ತಿಂಗಳು ಫೈಲ್ ಮಾಡಬಹುದು. ನೀವು ಸಂಬಳದ ವಿವರ ಕಳುಹಿಸಿ. ನಾವು ಫೈಲ್ ಮಾಡಿ, ರಸೀದಿ ಮತ್ತು ಚಲನ್‌ಗಳನ್ನು ನಿಮಗೆ ಇಮೇಲ್ ಮಾಡುತ್ತೇವೆ.

ನಮ್ಮ ಸ್ಥಾಪಕರು EPFOನಲ್ಲಿ 35 ವರ್ಷ ಕೆಲಸ ಮಾಡಿದ್ದರು. PF ನಿಯಮಗಳನ್ನು ಅವರು ನಮಗೆ ಕಲಿಸಿದರು.

ನೀವು ನಮ್ಮೊಂದಿಗೆ ಇಂಗ್ಲಿಷ್ ಅಥವಾ ಕನ್ನಡದಲ್ಲಿ ಮಾತನಾಡಬಹುದು. ಹಿಂದಿಯಲ್ಲೂ ನಾವು ಸಹಾಯ ಮಾಡುತ್ತೇವೆ. ನಮ್ಮ {% include link.html path="epf-consultancy-service" label="PF ಮಾಸಿಕ ಫೈಲಿಂಗ್" arrow=false %} ಮತ್ತು {% include link.html path="esi-consultancy-service" label="ESI ಮಾಸಿಕ ಫೈಲಿಂಗ್" arrow=false %} ಸೇವೆಗಳನ್ನು ನೋಡಿ.
