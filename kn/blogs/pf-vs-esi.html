PF ಮತ್ತು ESI: ಉದ್ಯೋಗದಾತರಿಗೆ ವ್ಯತ್ಯಾಸಗಳು, ಒಂದೇ ಕೋಷ್ಟಕದಲ್ಲಿ

PF ಮತ್ತು ESI ಎರಡು ಬೇರೆ ಬೇರೆ ಯೋಜನೆಗಳು. ಅವುಗಳನ್ನು ಎರಡು ಬೇರೆ ಸರ್ಕಾರಿ ಇಲಾಖೆಗಳು ನಡೆಸುತ್ತವೆ. ಅವುಗಳ ಸಿಬ್ಬಂದಿ ಮಿತಿ, ವೇತನ ಮಿತಿ ಮತ್ತು ದರಗಳು ಬೇರೆ. ಅವು ಹೇಗೆ ಬೇರೆ ಎಂದು ಇಲ್ಲಿ ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ನೋಡಿ.

ESI (ಉದ್ಯೋಗಿಗಳ ರಾಜ್ಯ ವಿಮೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ನೀಡುತ್ತದೆ. ಅನಾರೋಗ್ಯ, ಗಾಯ ಅಥವಾ ಹೆರಿಗೆಯಿಂದ ಕೆಲಸ ಮಾಡಲು ಆಗದಿದ್ದಾಗ ಹಣದ ಸಹಾಯವನ್ನೂ ನೀಡುತ್ತದೆ. {% include link.html path="blogs/esi-benefits-for-employees" label="ಉದ್ಯೋಗಿಗಳಿಗೆ ESI ಸೌಲಭ್ಯಗಳು" arrow=false %} ಓದಿ.

ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ಯಾವಾಗ ಅನ್ವಯಿಸುತ್ತದೆ20 ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ, ಯಾವುದೇ ಉದ್ಯಮವಾಗಿದ್ದರೂ10 ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ, ಎಲ್ಲ ರಾಜ್ಯಗಳಲ್ಲೂ. ಋತುಮಾನದ ಕಾರ್ಖಾನೆಗಳಿಗೆ ESI ಅನ್ವಯಿಸುವುದಿಲ್ಲ. ಕೆಲವು ಅಪಾಯಕಾರಿ ಕೆಲಸಗಳಿಗೆ, 1 ಉದ್ಯೋಗಿ ಇದ್ದರೂ ESI ಅನ್ವಯಿಸಬಹುದು. ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.
ಯಾರನ್ನು ಎಣಿಸಬೇಕುಎಲ್ಲ ಸಿಬ್ಬಂದಿ: ತಾತ್ಕಾಲಿಕ ಮತ್ತು ದಿನಗೂಲಿ ಸಿಬ್ಬಂದಿ, ಗುತ್ತಿಗೆದಾರರು ಕಳುಹಿಸುವ ಸಿಬ್ಬಂದಿ ಹಾಗೂ ವೇತನ ಮಿತಿ ದಾಟಿದ ಸಿಬ್ಬಂದಿಯೂ ಸೇರಿ. ಅಪ್ರೆಂಟಿಸ್‌ಗಳನ್ನು ಎಣಿಸಬೇಡಿ.PFನಂತೆಯೇ (ESI ವೇತನ ಮಿತಿ ದಾಟಿದ ಸಿಬ್ಬಂದಿಯನ್ನೂ ಎಣಿಸಬೇಕು)
ಒಮ್ಮೆ ಅನ್ವಯಿಸಿದರೆನಂತರ ಸಿಬ್ಬಂದಿ 20ಕ್ಕಿಂತ ಕಡಿಮೆಯಾದರೂ ಅನ್ವಯಿಸುತ್ತಲೇ ಇರುತ್ತದೆನಂತರ ಸಿಬ್ಬಂದಿ 10ಕ್ಕಿಂತ ಕಡಿಮೆಯಾದರೂ ಅನ್ವಯಿಸುತ್ತಲೇ ಇರುತ್ತದೆ

ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ಸಂಖ್ಯೆUAN (ಅವರ PF ಖಾತೆ ಸಂಖ್ಯೆ). ಹೊಸ ಸಿಬ್ಬಂದಿ UMANG ಆ್ಯಪ್‌ನಲ್ಲಿ ಬೇಗ ಮುಗಿಯುವ ಮುಖದ ಸ್ಕ್ಯಾನ್ ಮೂಲಕ UAN ಪಡೆಯುತ್ತಾರೆ.IP (Insured Person, ವಿಮೆ ಪಡೆದ ವ್ಯಕ್ತಿ) ಸಂಖ್ಯೆ, ಅಂದರೆ ಅವರ ESI ಸಂಖ್ಯೆ

ಕೋಷ್ಟಕದಲ್ಲಿ ತೋರಿಸಲು ಆಗದ ಇನ್ನೆರಡು ವಿಷಯಗಳು:

PF ವೇತನ {{ epf.wage_ceiling_text }} ದಾಟಿರುವ ಸಿಬ್ಬಂದಿ:

  • ಈಗಾಗಲೇ PFನಲ್ಲಿ ಇರುವವರು: ಅವರು PFನಲ್ಲೇ ಉಳಿಯುತ್ತಾರೆ.
  • PF ವೇತನ {{ epf.wage_ceiling_text }} ದಾಟಿರುವ, ಹಿಂದೆಂದೂ PFನಲ್ಲಿ ಇರದ ಹೊಸದಾಗಿ ಸೇರುವವರು: ನೀವು ಮತ್ತು ಅವರು ಇಬ್ಬರೂ ಲಿಖಿತವಾಗಿ ಒಪ್ಪಿದರೆ PFಗೆ ಸೇರಬಹುದು.
  • ಹಿಂದಿನ ಕೆಲಸದಲ್ಲಿ PFನಲ್ಲಿ ಇದ್ದರೇ? ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

ಇನ್ನಷ್ಟು ತಿಳಿಯಲು {% include link.html path="blogs/pf-wage-limit-25000" label="PF ವೇತನ ಮಿತಿ ಈಗ ₹25,000" arrow=false %} ಓದಿ.

ESI ವಂತಿಗೆ ಅವಧಿಗಳು: ESIಗೆ ವರ್ಷಕ್ಕೆ ಎರಡು ವಂತಿಗೆ ಅವಧಿಗಳಿವೆ: {{ esi.contribution_periods_text_kn }}. ಆದರೂ ESI ಅನ್ನು ಪ್ರತಿ ತಿಂಗಳು, ಮುಂದಿನ ತಿಂಗಳ {{ esi.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು.

ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದೀರಾ? UMANG ಮುಖದ ಸ್ಕ್ಯಾನ್‌ಗೆ ನಾವು ಹೊಸ ಸಿಬ್ಬಂದಿಗೆ ಮಾರ್ಗದರ್ಶನ ನೀಡುತ್ತೇವೆ. ESIC ಪೋರ್ಟಲ್‌ನಲ್ಲಿ IP ಸಂಖ್ಯೆಗಳನ್ನು ನಾವು ಮಾಡಿಕೊಡುತ್ತೇವೆ.

{% include result-call.html line="PF, ESI ಅಥವಾ ಎರಡೂ ನಿಮಗೆ ಅನ್ವಯಿಸುತ್ತವೆಯೇ ಎಂದು ಖಚಿತವಿಲ್ಲವೇ? ನಮಗೆ ಕರೆ ಮಾಡಿ. PF ಮತ್ತು ESI ಅನ್ವಯಿಸುತ್ತದೆಯೇ ಎಂದು ನಾವು ಹೇಳುತ್ತೇವೆ." %}

ಎರಡೂ ಯಾವಾಗ ಬೇಕು

ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ ಎಷ್ಟು ಸಿಬ್ಬಂದಿ ಇದ್ದಾರೆ ಎಂದು ನೋಡಿ.

  • 10ರಿಂದ 19 ಸಿಬ್ಬಂದಿ: ESI ಅನ್ವಯಿಸುತ್ತದೆ, ಋತುಮಾನದ ಕಾರ್ಖಾನೆಗಳನ್ನು ಬಿಟ್ಟು. ಸಿಬ್ಬಂದಿ 20 ಆದಾಗ PF ಅನ್ವಯಿಸುತ್ತದೆ.
  • 20 ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ: ಯಾವುದೇ ಉದ್ಯಮವಾಗಿದ್ದರೂ PF ಅನ್ವಯಿಸುತ್ತದೆ. ESI ಕೂಡ ಅನ್ವಯಿಸುತ್ತದೆ, ಋತುಮಾನದ ಕಾರ್ಖಾನೆಗಳನ್ನು ಬಿಟ್ಟು.

ನಂತರ ಪ್ರತಿ ಉದ್ಯೋಗಿಯನ್ನು ನೋಡಿ. PF ಮತ್ತು ESIಗೆ ಬೇರೆ ಬೇರೆ ವೇತನ ಮಿತಿಗಳಿವೆ. PF ವೇತನ ಮತ್ತು ESI ವೇತನವನ್ನು ಬೇರೆ ಬೇರೆ ರೀತಿಯಲ್ಲಿ ಲೆಕ್ಕ ಹಾಕುತ್ತಾರೆ. ಆದ್ದರಿಂದ ಒಬ್ಬ ಉದ್ಯೋಗಿ PFನಲ್ಲಿ, ESIನಲ್ಲಿ ಅಥವಾ ಎರಡರಲ್ಲೂ ಇರಬೇಕಾಗಬಹುದು. ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದೀರಾ? ಯಾರು PF ಮತ್ತು ESIನಲ್ಲಿ ಇರಬೇಕು ಎಂದು ನಾವು ಪರಿಶೀಲಿಸುತ್ತೇವೆ.

ಈಗಷ್ಟೇ 10 ಅಥವಾ 20 ಸಿಬ್ಬಂದಿ ಆಗಿದ್ದಾರೆಯೇ? {% include link.html path="blogs/pf-esi-reached-10-or-20-staff" label="ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ ಈಗಷ್ಟೇ 10 ಅಥವಾ 20 ಸಿಬ್ಬಂದಿ ಆಗಿದ್ದಾರೆ: ಮುಂದೆ ಏನು ಮಾಡಬೇಕು" arrow=false %} ಓದಿ.

ಎರಡಕ್ಕೂ ನೋಂದಣಿ

ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದೀರಾ? ನಿಮ್ಮ ವ್ಯಾಪಾರವನ್ನು PF, ESI ಅಥವಾ ಎರಡಕ್ಕೂ ನಾವು ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ. ನಮಗೆ ಯಾವ ದಾಖಲೆಗಳು ಬೇಕು ಎಂದು ನೀವು ಕರೆ ಮಾಡಿದಾಗ ಹೇಳುತ್ತೇವೆ. ನಿಮ್ಮ ಎಲ್ಲ ದಾಖಲೆಗಳು ನಮಗೆ ಸಿಕ್ಕ ನಂತರ, ಕೆಲವೇ ಗಂಟೆಗಳಲ್ಲಿ ಮುಗಿಯುತ್ತದೆ. {% include link.html path="pf-registration" label="PF ನೋಂದಣಿ" arrow=false %} ಮತ್ತು {% include link.html path="esi-registration" label="ESI ನೋಂದಣಿ" arrow=false %} ನೋಡಿ.

ನೋಂದಣಿಯ ನಂತರ, ಎರಡನ್ನೂ ಪ್ರತಿ ತಿಂಗಳು {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು. ನಮ್ಮ ಸೇವೆ ಪಡೆಯುತ್ತಿದ್ದೀರಾ? ಪ್ರತಿ ತಿಂಗಳು ನಾವು ECR (ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ಸಂಬಳ ಮತ್ತು PFನ ಮಾಸಿಕ ಪಟ್ಟಿ, PF ಇಲಾಖೆಗೆ ಕಳುಹಿಸುವುದು) ಮತ್ತು ನಿಮ್ಮ ಮಾಸಿಕ ESI ವಿವರಗಳನ್ನು ಫೈಲ್ ಮಾಡುತ್ತೇವೆ. ನೀವು {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಲು ಆಗುವಂತೆ, ಪಾವತಿ ಚೀಟಿಯನ್ನು (ಚಲನ್) ನಾವು ಸಮಯಕ್ಕೆ ಸಿದ್ಧಮಾಡುತ್ತೇವೆ. ಅಥವಾ ಹಣವನ್ನು ನಮಗೆ ಕಳುಹಿಸಿ, ನಾವು ಕಟ್ಟುತ್ತೇವೆ.

ಎರಡನ್ನೂ ತಡವಾಗಿ ಕಟ್ಟಿದರೆ ಹೆಚ್ಚುವರಿ ಹಣ ಆಗುತ್ತದೆ. {% include link.html path="blogs/epf-late-payment-penalty" label="PF ತಡವಾಗಿ ಕಟ್ಟಿದರೆ ಏನಾಗುತ್ತದೆ?" arrow=false %} ಮತ್ತು {% include link.html path="blogs/esi-late-payment-penalty" label="ESI ತಡವಾಗಿ ಕಟ್ಟಿದರೆ ಏನಾಗುತ್ತದೆ?" arrow=false %} ಓದಿ.
