PF ವೇತನ ಮಿತಿ ಈಗ ₹25,000: ಉದ್ಯೋಗದಾತರು ಏನು ಬದಲಿಸಬೇಕು

{{ epf.wage_ceiling_from_kn }}ರಿಂದ PF ವೇತನ ಮಿತಿ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_text }}. ಮೊದಲು ಇದು {{ epf.wage_ceiling_old_text }} ಇತ್ತು. ಹಾಗಾಗಿ ನಿಮ್ಮ ಇನ್ನಷ್ಟು ಸಿಬ್ಬಂದಿ ಈಗ PFನಲ್ಲಿ ಇರಬೇಕಾಗಬಹುದು. ಯಾರು ಇರಬೇಕು ಮತ್ತು ನೀವು ಏನು ಬದಲಿಸಬೇಕು ಎಂಬುದು ಇಲ್ಲಿದೆ.

17 ಸೆಪ್ಟೆಂಬರ್ 2026ರಂದು ಏನು ಬದಲಾಯಿತು

PF (ಭವಿಷ್ಯ ನಿಧಿ, EPF ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ಉಳಿತಾಯ ಮತ್ತು ಪಿಂಚಣಿ ನೀಡುತ್ತದೆ. PF ವೇತನ ಒಂದು ಮಿತಿಯಷ್ಟು ಅಥವಾ ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ PFನಲ್ಲಿ ಇರಬೇಕು, ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ. ಈ ಮಿತಿಯನ್ನು PF ವೇತನ ಮಿತಿ (wage ceiling) ಎಂದು ಕರೆಯುತ್ತಾರೆ.

ಸೆಪ್ಟೆಂಬರ್ 2014ರಿಂದ ಈ ಮಿತಿ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_old_text }} ಇತ್ತು. ಸರ್ಕಾರ ಇದನ್ನು {{ epf.wage_ceiling_from_kn }}ರಿಂದ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_text }}ಕ್ಕೆ ಏರಿಸಿದೆ.

PF ನಿಯಮಗಳು ಈಗ {{ site.data.facts.law_in_force_kn }}ರಿಂದ ಜಾರಿಯಲ್ಲಿರುವ {{ site.data.facts.law_kn }} ಮತ್ತು EPF ಯೋಜನೆ, 2026ರಿಂದ ಬರುತ್ತವೆ.

ಉದ್ಯೋಗಿ ತಮ್ಮ PF ವೇತನದ {{ epf.employee_rate_pct }}% ಕಟ್ಟುತ್ತಾರೆ. ನೀವು {{ epf.employer_rate_pct }}% ಕಟ್ಟುತ್ತೀರಿ. ಅದು ಅವರ PF ಉಳಿತಾಯ ಮತ್ತು ಪಿಂಚಣಿ (EPS) ನಡುವೆ ಹಂಚಿಕೆಯಾಗುತ್ತದೆ. PF ಅನ್ನು ಮುಂದಿನ ತಿಂಗಳ {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು.

ಈಗ ಯಾವ ಸಿಬ್ಬಂದಿ PFನಲ್ಲಿ ಇರಬೇಕು

PF ವೇತನ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇರುವ ಸಿಬ್ಬಂದಿ PFನಲ್ಲಿ ಇರಬೇಕು, ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ.

PF ವೇತನ ಎಂದರೆ ಮೂಲ ವೇತನ ಮತ್ತು DA (ತುಟ್ಟಿ ಭತ್ಯೆ: ಬೆಲೆ ಏರಿದಂತೆ ಹೆಚ್ಚಾಗುವ ಭತ್ಯೆ). ಇದು ಪೂರ್ತಿ ಸಂಬಳ ಅಲ್ಲ. ಆದರೆ PF ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು PF ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

ಉದಾಹರಣೆ: ಒಬ್ಬ ಉದ್ಯೋಗಿಯ ಮೂಲ ವೇತನ ಮತ್ತು DA ತಿಂಗಳಿಗೆ ₹20,000. ಅವರ ಒಟ್ಟು ಸಂಬಳ ₹35,000. ₹35,000ದ ಅರ್ಧ ₹17,500. ಹಾಗಾಗಿ ಅವರ PF ವೇತನ ₹20,000. ಇದು ಹಳೆಯ {{ epf.wage_ceiling_old_text }} ಮಿತಿಗಿಂತ ಹೆಚ್ಚು. ಹಾಗಾಗಿ ಅವರು PFನಲ್ಲಿ ಇರದಿದ್ದರೆ, ಸೇರಬೇಕಾಗಿರಲಿಲ್ಲ. ಇದು {{ epf.wage_ceiling_text }}ಕ್ಕಿಂತ ಕಡಿಮೆ. ಹಾಗಾಗಿ ಈಗ ಅವರು PFನಲ್ಲಿ ಇರಬೇಕು. ಪ್ರತಿ ತಿಂಗಳು ಉದ್ಯೋಗಿ ₹2,400 ({{ epf.employee_rate_pct }}%) ಕಟ್ಟುತ್ತಾರೆ. ನೀವು ನಿಮ್ಮ PF ಪಾಲಾಗಿ ₹2,400 ({{ epf.employer_rate_pct }}%) ಕಟ್ಟುತ್ತೀರಿ. ಇದು ಅಂದಾಜು. ನಿಮ್ಮ ಸ್ವಂತ ಅಂಕಿಗಳನ್ನು ನಮ್ಮ {% include link.html path="epf-contribution-calculator" label="PF ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರ" arrow=false %} ಸಾಧನದಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.

ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ PF ಅನ್ವಯಿಸುತ್ತದೆಯೇ ಎಂದೇ ಖಚಿತವಿಲ್ಲವೇ? {{ epf.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿ ಇದ್ದರೆ PF ಅನ್ವಯಿಸುತ್ತದೆ. {% include link.html path="blogs/epf-applicability-threshold" label="PF: ಯಾರು ನೋಂದಣಿ ಮಾಡಬೇಕು" arrow=false %} ಓದಿ.

₹25,000 ದಾಟಿದ ಸಿಬ್ಬಂದಿ: ಯಾರು ಸೇರಬಹುದು, ಯಾರು ಉಳಿಯುತ್ತಾರೆ

  • ಈಗಾಗಲೇ PFನಲ್ಲಿ ಇರುವವರು: PF ವೇತನ {{ epf.wage_ceiling_text }} ದಾಟಿದರೂ ಅವರು PFನಲ್ಲೇ ಉಳಿಯುತ್ತಾರೆ. ಸಂಬಳ ಹೆಚ್ಚಾಯಿತು ಎಂದು ಅವರು PF ಬಿಡುವಂತಿಲ್ಲ.
  • PF ವೇತನ {{ epf.wage_ceiling_text }} ದಾಟಿರುವ, ಹಿಂದೆಂದೂ PFನಲ್ಲಿ ಇರದ ಹೊಸದಾಗಿ ಸೇರುವವರು: ನೀವು ಮತ್ತು ಅವರು ಇಬ್ಬರೂ ಲಿಖಿತವಾಗಿ ಒಪ್ಪಿದರೆ PFಗೆ ಸೇರಬಹುದು.
  • ಹಿಂದಿನ ಕೆಲಸದಲ್ಲಿ PFನಲ್ಲಿ ಇದ್ದರೇ? ನಿರ್ಧರಿಸುವ ಮೊದಲು ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

{{ epf.min_employees }} ಸಿಬ್ಬಂದಿಯ ನಿಯಮಕ್ಕೆ ಎಣಿಸುವಾಗ, ಮಿತಿ ದಾಟಿದ ಸಿಬ್ಬಂದಿಯನ್ನೂ ಎಣಿಸಬೇಕು.

ನಿಮ್ಮ ಸಂಬಳದ ಲೆಕ್ಕದಲ್ಲಿ (ಪೇರೋಲ್) ಏನು ಬದಲಿಸಬೇಕು

  1. ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಯ ಪಟ್ಟಿ ಮಾಡಿ. PF ವೇತನ ತಿಂಗಳಿಗೆ {{ epf.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇದ್ದು, ಇನ್ನೂ PFನಲ್ಲಿ ಇಲ್ಲದ ಎಲ್ಲರನ್ನೂ ಗುರುತಿಸಿ.
  2. ಅವರನ್ನು PFಗೆ ಸೇರಿಸಿ. ಯಾರು PFನಲ್ಲಿ ಇರಬೇಕು ಎಂದು ನಾವು ಪರಿಶೀಲಿಸುತ್ತೇವೆ. ಹಾಗಾಗಿ ನೀವು ಸರಿಯಾದವರನ್ನೇ ಸೇರಿಸುತ್ತೀರಿ. ಇನ್ನೂ UAN (ಅವರ PF ಖಾತೆ ಸಂಖ್ಯೆ) ಇಲ್ಲದ ಸಿಬ್ಬಂದಿ UMANG ಆ್ಯಪ್‌ನಲ್ಲಿ ಬೇಗ ಮುಗಿಯುವ ಮುಖದ ಸ್ಕ್ಯಾನ್ ಮೂಲಕ UAN ಪಡೆಯುತ್ತಾರೆ. ನಾವು ಅವರಿಗೆ ಮಾರ್ಗದರ್ಶನ ನೀಡುತ್ತೇವೆ.
  3. ನಿಮ್ಮ ಸಂಬಳದ ಶೀಟ್ ಅಥವಾ ಪೇರೋಲ್ ಸಾಫ್ಟ್‌ವೇರ್ ಅನ್ನು ಬದಲಿಸಿ. ಅದು {{ epf.wage_ceiling_old_text }} ಅಲ್ಲ, {{ epf.wage_ceiling_text }} ಮಿತಿಯನ್ನು ಬಳಸುತ್ತಿದೆಯೇ ಎಂದು ನೋಡಿ.
  4. 50% ನಿಯಮದಂತೆ PF ವೇತನವನ್ನು ಪರಿಶೀಲಿಸಿ. ಮೂಲ ವೇತನ ಮತ್ತು DA ಒಟ್ಟು ಸಂಬಳದ ಅರ್ಧಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು PF ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.
  5. {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಿ. ಪ್ರತಿ ತಿಂಗಳ PF ಅನ್ನು ಮುಂದಿನ ತಿಂಗಳ {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು. ನೀವು {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಲು ಆಗುವಂತೆ, ಪಾವತಿ ಚೀಟಿಯನ್ನು (ಚಲನ್) ನಾವು ಸಮಯಕ್ಕೆ ಸಿದ್ಧಮಾಡುತ್ತೇವೆ.
  6. ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ತಿಳಿಸಿ. ಅವರ PF ಪಾಲಿನಷ್ಟು ಅವರ ಕೈಗೆ ಸಿಗುವ ಸಂಬಳ ಕಡಿಮೆಯಾಗುತ್ತದೆ. ಆದರೆ ಆ ಹಣ ಅವರದೇ ಉಳಿತಾಯ. {% include link.html path="blogs/epf-benefits-for-employees" label="PF ಉದ್ಯೋಗಿಗಳಿಗೆ ಏನು ನೀಡುತ್ತದೆ" arrow=false %} ಎಂಬ ನಮ್ಮ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ಅವರೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳಿ.

ನೀವು IT ಕಂಪನಿ ನಡೆಸುತ್ತೀರಾ? {% include link.html path="industries/it-companies" label="IT ಕಂಪನಿಗಳಿಗೆ PF ಮತ್ತು ESI" arrow=false %} ಓದಿ. IT ಸಂಬಳಗಳಿಗೆ {{ epf.wage_ceiling_text }} ಮಿತಿಯ ಬಗ್ಗೆ ಅದರಲ್ಲಿ ಇದೆ.

ಸೆಪ್ಟೆಂಬರ್ 2026ರ ಸಂಬಳ: EPFOನ FAQಗಳು ಏನು ಹೇಳುತ್ತವೆ

ಹೊಸ ಮಿತಿ ತಿಂಗಳ ಮಧ್ಯದಲ್ಲಿ, {{ epf.wage_ceiling_from_kn }}ರಂದು ಶುರುವಾಯಿತು. ಹೊಸ ಮಿತಿಯ ಬಗ್ಗೆ EPFOನ (ಸರ್ಕಾರದ PF ಇಲಾಖೆ) FAQಗಳ (ಸಾಮಾನ್ಯ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಗಳು) ಪ್ರಕಾರ ಸೆಪ್ಟೆಂಬರ್ 2026ಕ್ಕೆ ಒಂದೇ ECR (ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ಸಂಬಳ ಮತ್ತು PFನ ಮಾಸಿಕ ಪಟ್ಟಿ, PF ಇಲಾಖೆಗೆ ಕಳುಹಿಸುವುದು) ಕಳುಹಿಸಬೇಕು, ಅದರಲ್ಲಿ PF ಅನ್ನು ಎರಡು ಭಾಗಗಳಾಗಿ ಲೆಕ್ಕ ಹಾಕಬೇಕು:

  • 1ರಿಂದ 16 ಸೆಪ್ಟೆಂಬರ್: ಹಳೆಯ {{ epf.wage_ceiling_old_text }} ಮಿತಿಯಲ್ಲಿ
  • 17ರಿಂದ 30 ಸೆಪ್ಟೆಂಬರ್: ಹೊಸ {{ epf.wage_ceiling_text }} ಮಿತಿಯಲ್ಲಿ

ಹೊಸ {{ epf.wage_ceiling_text }} ಮಿತಿ EPS (ಪಿಂಚಣಿ) ವೇತನಕ್ಕೂ ಅನ್ವಯಿಸುತ್ತದೆ ಎಂದು FAQಗಳು ಹೇಳುತ್ತವೆ. ಈಗಾಗಲೇ {{ epf.wage_ceiling_text }}ಕ್ಕಿಂತ ಹೆಚ್ಚಿನ ವೇತನದ ಮೇಲೆ PF ಕಟ್ಟುತ್ತಿರುವ ಸಿಬ್ಬಂದಿ ಅದನ್ನು {{ epf.wage_ceiling_text }}ಕ್ಕೆ ಇಳಿಸಬೇಕಿಲ್ಲ.

ಸೆಪ್ಟೆಂಬರ್ 2026ರ ಸಂಬಳದ PF ಕಟ್ಟುವ ಕೊನೆಯ ದಿನಾಂಕವನ್ನು EPFO 31 ಅಕ್ಟೋಬರ್ 2026ಕ್ಕೆ ಮುಂದೂಡಿದೆ. ಇದು ಸೆಪ್ಟೆಂಬರ್‌ಗೆ ಮಾತ್ರ. ಅಕ್ಟೋಬರ್ 2026ರ ಸಂಬಳದ PF ಅನ್ನು 15 ನವೆಂಬರ್ 2026ರೊಳಗೆ ಕಟ್ಟಬೇಕು. ನಮಗೆ ಕರೆ ಮಾಡಿ, ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ಏನು ಮಾಡಬೇಕು ಎಂದು ನಾವು ಹೇಳುತ್ತೇವೆ.
