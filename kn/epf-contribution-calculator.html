PF ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರ

ಒಬ್ಬ ಉದ್ಯೋಗಿಯ PF ವೇತನವನ್ನು ಬರೆಯಿರಿ. ಉದ್ಯೋಗಿ ಎಷ್ಟು PF (ಭವಿಷ್ಯ ನಿಧಿ) ಕಟ್ಟುತ್ತಾರೆ, ನೀವು ಎಷ್ಟು ಕಟ್ಟುತ್ತೀರಿ, ಮತ್ತು ಅವರ ಪಿಂಚಣಿಗೆ ಎಷ್ಟು ಹೋಗುತ್ತದೆ ಎಂದು ನೋಡಿ.

{% include result-call.html tool="contribution" %}

PF ಹೇಗೆ ಲೆಕ್ಕ ಹಾಕಲಾಗುತ್ತದೆ

ಉದ್ಯೋಗಿ ತಮ್ಮ PF ವೇತನದ {{ epf.employee_rate_pct }}% ಕಟ್ಟುತ್ತಾರೆ. ಅದನ್ನು ನೀವು ಅವರ ಸಂಬಳದಿಂದ ಕಡಿತ ಮಾಡುತ್ತೀರಿ. ಅದೆಲ್ಲವೂ ಅವರ PF ಖಾತೆಗೆ ಹೋಗುತ್ತದೆ.

ನೀವೂ {{ epf.employer_rate_pct }}% ಕಟ್ಟುತ್ತೀರಿ. ಅದರ ಒಂದು ಭಾಗ ಉದ್ಯೋಗಿಯ ಪಿಂಚಣಿಗೆ ಹೋಗುತ್ತದೆ. ಇದನ್ನು EPS (ಉದ್ಯೋಗಿಗಳ ಪಿಂಚಣಿ ಯೋಜನೆ) ಎನ್ನುತ್ತಾರೆ: {{ epf.wage_ceiling_text }}ದವರೆಗಿನ PF ವೇತನದ 8.33%. ಅಂದರೆ ತಿಂಗಳಿಗೆ ಗರಿಷ್ಠ ₹2,083. ನಿಮ್ಮ {{ epf.employer_rate_pct }}%ನಲ್ಲಿ ಉಳಿದದ್ದು ಅವರ PF ಖಾತೆಗೆ ಹೋಗುತ್ತದೆ.

ಸರ್ಕಾರ ಹೆಸರಿಸಿರುವ ಕೆಲವು ವ್ಯಾಪಾರಗಳು 12%ರ ಬದಲು 10% ಕಟ್ಟುತ್ತವೆ. ಹೆಚ್ಚಿನ ವ್ಯಾಪಾರಗಳು 12% ಕಟ್ಟುತ್ತವೆ.

{{ epf.wage_ceiling_from_kn }}ರಿಂದ PF ವೇತನ ಮಿತಿ {{ epf.wage_ceiling_text }} (ಹಿಂದೆ {{ epf.wage_ceiling_old_text }} ಇತ್ತು). PFನಲ್ಲಿರುವ ಉದ್ಯೋಗಿಯ PF ವೇತನ {{ epf.wage_ceiling_text }}ಕ್ಕಿಂತ ಹೆಚ್ಚಿದ್ದರೆ, ಕನಿಷ್ಠ {{ epf.wage_ceiling_text }}ದ ಮೇಲೆ PF ಕಟ್ಟಬೇಕು. ನೀವು ಮತ್ತು ಉದ್ಯೋಗಿ ಇಬ್ಬರೂ ಒಪ್ಪಿದರೆ, ಪೂರ್ತಿ PF ವೇತನದ ಮೇಲೆ ಕಟ್ಟಬಹುದು.

ಈ ಲೆಕ್ಕಾಚಾರ ಯಾವಾಗಲೂ PF ವೇತನದ 8.33% ({{ epf.wage_ceiling_text }}ದವರೆಗೆ) ಪಿಂಚಣಿಗೆ ಹಾಕುತ್ತದೆ. 58 ಅಥವಾ ಹೆಚ್ಚು ವಯಸ್ಸಿನ ಸಿಬ್ಬಂದಿಗೆ, ಅಥವಾ PF ವೇತನ {{ epf.wage_ceiling_text }}ಕ್ಕಿಂತ ಹೆಚ್ಚಿರುವ ಹೊಸ ಸಿಬ್ಬಂದಿಗೆ ಇದು ಬೇರೆ ಇರಬಹುದು. ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

PF (EPF ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) ಅನ್ನು ಮುಂದಿನ ತಿಂಗಳ {{ epf.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು.

ಗಮನಿಸಿ: ಈ ಲೆಕ್ಕಾಚಾರ ಅಂದಾಜು ಮೊತ್ತ ನೀಡುತ್ತದೆ. ಪೈಸೆಗಳನ್ನು ರೂಪಾಯಿಗೆ ಸರಿಪಡಿಸುವ ರೀತಿಯಿಂದ, ಅಂತಿಮ ಮೊತ್ತ ಸ್ವಲ್ಪ ಬೇರೆ ಆಗಬಹುದು. {{ site.data.facts.tools_checked_kn }}ರ ನಿಯಮಗಳ ಪ್ರಕಾರ ಪರಿಶೀಲಿಸಲಾಗಿದೆ.
