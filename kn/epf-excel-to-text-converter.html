EPF ಎಕ್ಸೆಲ್‌ನಿಂದ ಟೆಕ್ಸ್ಟ್ ಪರಿವರ್ತಕ

ನಿಮ್ಮ ECR ಎಕ್ಸೆಲ್ ಶೀಟ್ ಅನ್ನು EPFO ಪೋರ್ಟಲ್‌ಗೆ ಬೇಕಾದ ಟೆಕ್ಸ್ಟ್ ಫೈಲ್ ಆಗಿ ಬದಲಿಸಿ. ECR ಎಂದರೆ ನೀವು EPFOಗೆ (PF ಇಲಾಖೆ) ಅಪ್‌ಲೋಡ್ ಮಾಡುವ, ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ಸಂಬಳ ಮತ್ತು PF (ಭವಿಷ್ಯ ನಿಧಿ)ನ ಮಾಸಿಕ ಪಟ್ಟಿ. ನಿಮ್ಮ ಫೈಲ್ ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲೇ ಇರುತ್ತದೆ.

ನಿಮ್ಮ ಫೈಲ್ ಬದಲಿಸಿ

  1. ECR ಎಕ್ಸೆಲ್ ಶೀಟ್ ತುಂಬಿ

    ನಮ್ಮ ಎಕ್ಸೆಲ್ ನಮೂನೆಯನ್ನು ಬಳಸಿ, ಆಗ ಕಾಲಂಗಳು ಸರಿಯಾದ ಕ್ರಮದಲ್ಲಿ ಇರುತ್ತವೆ. ಶೀರ್ಷಿಕೆ ಸಾಲನ್ನು ಅಳಿಸಬೇಡಿ. ಪರಿವರ್ತಕ ಅದನ್ನು ತಾನೇ ಬಿಟ್ಟುಬಿಡುತ್ತದೆ.

    ECR ಎಕ್ಸೆಲ್ ನಮೂನೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ⁠{% include icon.html name="arrow" size="18" %}

  2. ತುಂಬಿದ ಎಕ್ಸೆಲ್ ಫೈಲ್ ಆರಿಸಿ

  3. ಟೆಕ್ಸ್ಟ್ ಫೈಲ್ ಪಡೆಯಿರಿ

{% include result-call.html tool="converter" %}

ಟೆಕ್ಸ್ಟ್ ಫೈಲ್ ಅನ್ನು ನೀವೇ ಮಾಡುವುದು ಹೇಗೆ

ಎಕ್ಸೆಲ್ ಮತ್ತು Notepadನಲ್ಲಿ ಇದನ್ನು ನೀವೇ ಮಾಡಬಹುದು:

  1. ತುಂಬಿದ ECR ಎಕ್ಸೆಲ್ ಶೀಟ್ ತೆರೆಯಿರಿ. ಶೀರ್ಷಿಕೆ ಸಾಲು ಮತ್ತು ಖಾಲಿ ಸಾಲುಗಳನ್ನು ಅಳಿಸಿ.
  2. ಅದನ್ನು CSV ಆಗಿ ಉಳಿಸಿ: File → Save As → CSV (Comma delimited). ಎಕ್ಸೆಲ್ ಮುಚ್ಚಿ.
  3. CSV ಫೈಲ್ ಮೇಲೆ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ, Notepadನಲ್ಲಿ ತೆರೆಯಿರಿ.
  4. ಪ್ರತಿ ಕಾಮಾವನ್ನು #~# ಆಗಿ ಬದಲಿಸಿ: Edit → Replace, , ಮತ್ತು #~# ಟೈಪ್ ಮಾಡಿ, ನಂತರ Replace All.
  5. ಫೈಲ್ ಹೆಸರಿನಲ್ಲಿ ಖಾಲಿ ಜಾಗ ಇಲ್ಲದಂತೆ, ಅದನ್ನು .txt ಫೈಲ್ ಆಗಿ ಉಳಿಸಿ.

ಹೆಸರು ಅಥವಾ ಸಂಖ್ಯೆಯಲ್ಲಿ ಕಾಮಾ ಇದ್ದರೆ, ಅಥವಾ ಎಕ್ಸೆಲ್ UAN (ಉದ್ಯೋಗಿಯ PF ಖಾತೆ ಸಂಖ್ಯೆ) ಅನ್ನು 1.00123E+11 ಎಂದು ತೋರಿಸಿದರೆ, ಇದು ತಪ್ಪಾಗುತ್ತದೆ. ಪರಿವರ್ತಕದಲ್ಲಿ ಈ ಎರಡೂ ತಪ್ಪುಗಳು ಆಗುವುದಿಲ್ಲ.

ಗಮನಿಸಿ: ಪರಿವರ್ತಕ ಫೈಲ್‌ನ ರೂಪವನ್ನು ಮಾತ್ರ ಬದಲಿಸುತ್ತದೆ. ನಿಮ್ಮ ಅಂಕಿಗಳನ್ನು ಪರಿಶೀಲಿಸುವುದಿಲ್ಲ. EPFOಗೆ ಫೈಲ್ ಅಪ್‌ಲೋಡ್ ಮಾಡುವ ಮೊದಲು ಮೊತ್ತಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.
