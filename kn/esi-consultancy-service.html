ESI ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ಅನ್ವಯಿಸುತ್ತದೆಯೇ?

  • {{ esi.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಉದ್ಯೋಗಿಗಳು
  • {{ esi.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ತಿಂಗಳ ESI ವೇತನ: ಈ ಸಿಬ್ಬಂದಿ ಸೇರಲೇಬೇಕು

ESI (ಉದ್ಯೋಗಿಗಳ ರಾಜ್ಯ ವಿಮೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ನೀಡುತ್ತದೆ. ಅನಾರೋಗ್ಯ, ಗಾಯ ಅಥವಾ ಹೆರಿಗೆಯಿಂದ ಕೆಲಸ ಮಾಡಲು ಆಗದಿದ್ದಾಗ ಹಣದ ಸಹಾಯವನ್ನೂ ನೀಡುತ್ತದೆ. ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ {{ esi.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಉದ್ಯೋಗಿಗಳು ಇದ್ದರೆ ESI ಅನ್ವಯಿಸುತ್ತದೆ. ಈ ನಿಯಮ ಎಲ್ಲ ರಾಜ್ಯಗಳಲ್ಲೂ ಒಂದೇ. ಋತುಮಾನದ ಕಾರ್ಖಾನೆಗಳಿಗೆ ಇದು ಅನ್ವಯಿಸುವುದಿಲ್ಲ. ಒಮ್ಮೆ ESI ಅನ್ವಯಿಸಿದರೆ, ನಂತರ ಸಿಬ್ಬಂದಿ {{ esi.min_employees }}ಕ್ಕಿಂತ ಕಡಿಮೆಯಾದರೂ ಅದು ಮುಂದುವರಿಯುತ್ತದೆ.

ESI ವೇತನ ತಿಂಗಳಿಗೆ {{ esi.wage_ceiling_text }} ವರೆಗೆ ಇರುವ ಸಿಬ್ಬಂದಿ ESIನಲ್ಲಿ ಇರಲೇಬೇಕು. ESI ವೇತನ ಎಂದರೆ ತಿಂಗಳ ಸಂಬಳದಿಂದ HRA (ಮನೆ ಬಾಡಿಗೆ ಭತ್ಯೆ) ಮತ್ತು ಓವರ್‌ಟೈಮ್‌ನಂತಹ ಕೆಲವು ಭಾಗಗಳನ್ನು ಬಿಟ್ಟು ಉಳಿದದ್ದು. ಇದನ್ನು ನಾವು ನಿಮಗಾಗಿ ಪರಿಶೀಲಿಸುತ್ತೇವೆ.

ನಾವು ನಿಮಗಾಗಿ ಮಾಡುವುದು

ನೀವು ಸಂಬಳದ ವಿವರ ಕಳುಹಿಸಿ. ESI ಕೆಲಸ ನಾವು ಮಾಡುತ್ತೇವೆ.

ಒಮ್ಮೆ

ನೀವು ಆರಂಭಿಸುವಾಗ

  • ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ಇನ್ನೂ ನೋಂದಣಿ ಆಗಿಲ್ಲದಿದ್ದರೆ, ನಾವು ESI ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ.
  • ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ, ನಿಮ್ಮ ಈಗಿನ ಸಿಬ್ಬಂದಿಯನ್ನು ESIಗೆ ಸೇರಿಸುತ್ತೇವೆ. ಈಗಾಗಲೇ IP ಸಂಖ್ಯೆ (ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ESI ಸಂಖ್ಯೆ, ಜೀವನಪೂರ್ತಿ ಒಂದೇ ಇರುತ್ತದೆ) ಇರುವವರು ಅದನ್ನೇ ಉಳಿಸಿಕೊಳ್ಳುತ್ತಾರೆ. ಉಳಿದವರಿಗೆ ನಾವು IP ಸಂಖ್ಯೆ ಮಾಡಿಕೊಡುತ್ತೇವೆ.
  • ಈಗಾಗಲೇ ನೋಂದಣಿ ಆಗಿದೆಯೇ? ನಮಗೆ ಬೇಕಾದ ದಾಖಲೆಗಳನ್ನು ನೀವು ಕಳುಹಿಸಿದ ನಂತರ, ಮುಂದಿನ ಕೊನೆಯ ದಿನಾಂಕದಿಂದ ನಾವು ಫೈಲ್ ಮಾಡುತ್ತೇವೆ.

ಮಾಸಿಕ

ಪ್ರತಿ ತಿಂಗಳು

  • ನಿಮ್ಮ ಮಾಸಿಕ ESI ವಿವರಗಳನ್ನು ESICಗೆ (ESI ಇಲಾಖೆ) ಸಮಯಕ್ಕೆ ಸರಿಯಾಗಿ ಫೈಲ್ ಮಾಡುತ್ತೇವೆ.
  • ಹೊಸದಾಗಿ ಸೇರುವ ಸಿಬ್ಬಂದಿಯನ್ನು ಸೇರಿಸುತ್ತೇವೆ, ಮತ್ತು ಕೆಲಸ ಬಿಟ್ಟವರು ಬಿಟ್ಟ ದಿನಾಂಕವನ್ನು ನಮೂದಿಸುತ್ತೇವೆ.
  • ಚಲನ್ (ESI ಪಾವತಿ ಚೀಟಿ) ಅನ್ನು ನಿಮಗೆ ಇಮೇಲ್ ಮಾಡುತ್ತೇವೆ. ಮುಂದಿನ ತಿಂಗಳ {{ esi.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಅದನ್ನು ಕಟ್ಟಿ, ಅಥವಾ ಹಣವನ್ನು ನಮಗೆ ಕಳುಹಿಸಿ, ನಾವು ಕಟ್ಟುತ್ತೇವೆ.

ಬೇಕಾದಾಗ

ನಿಮಗೆ ಸಹಾಯ ಬೇಕಾದಾಗ

  • ಅನಾರೋಗ್ಯ ಅಥವಾ ಹೆರಿಗೆ ಸೌಲಭ್ಯದಂತಹ ESI ಕ್ಲೇಮ್‌ಗಳಲ್ಲಿ ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ಸಹಾಯ ಮಾಡುತ್ತೇವೆ.
  • ಅವರ ESI ವಿವರಗಳನ್ನು ಸರಿಯಾಗಿ ಇಡುತ್ತೇವೆ: ಆಧಾರ್, ಬ್ಯಾಂಕ್ ಖಾತೆ, ಹೆಸರು ಮತ್ತು ಹುಟ್ಟಿದ ದಿನಾಂಕ.
  • ನಿಮ್ಮ ESI ದಾಖಲೆಗಳನ್ನು ಪರಿಶೀಲನೆಗೆ ಸಿದ್ಧವಾಗಿಡುತ್ತೇವೆ, ಮತ್ತು ESI ತಪಾಸಣೆಯ ಸಮಯದಲ್ಲಿ ನಿಮಗೆ ನೆರವಾಗುತ್ತೇವೆ.
