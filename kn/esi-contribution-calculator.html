ESI ವಂತಿಗೆ ಲೆಕ್ಕಾಚಾರ

ಉದ್ಯೋಗಿಯ ESI ವೇತನವನ್ನು ಬರೆಯಿರಿ. ಉದ್ಯೋಗಿ ಎಷ್ಟು ESI (ಉದ್ಯೋಗಿಗಳ ರಾಜ್ಯ ವಿಮೆ) ಕಟ್ಟುತ್ತಾರೆ, ಮತ್ತು ನೀವು ಎಷ್ಟು ಕಟ್ಟುತ್ತೀರಿ ಎಂದು ನೋಡಿ.

{% include result-call.html tool="contribution" %}

ESI ಹೇಗೆ ಲೆಕ್ಕ ಹಾಕಲಾಗುತ್ತದೆ

ಪ್ರತಿ ತಿಂಗಳು ESI ಎಂದರೆ ESI ವೇತನದ {{ esi.total_rate_pct }}%. ಉದ್ಯೋಗಿ {{ esi.employee_rate_pct }}% ಕಟ್ಟುತ್ತಾರೆ, ಅದನ್ನು ನೀವು ಅವರ ಸಂಬಳದಿಂದ ಕಡಿತ ಮಾಡುತ್ತೀರಿ. ನೀವು {{ esi.employer_rate_pct }}% ಕಟ್ಟುತ್ತೀರಿ.

ESI ವೇತನ ತಿಂಗಳಿಗೆ {{ esi.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ಇರುವ ಉದ್ಯೋಗಿಗಳಿಗೆ ESI ಕಟ್ಟಲಾಗುತ್ತದೆ (ವಿಕಲಚೇತನ ವ್ಯಕ್ತಿಗೆ {{ esi.wage_ceiling_pwd_text }}).

ESI ವೇತನ ಎಂದರೆ ತಿಂಗಳ ಸಂಬಳದಿಂದ HRA (ಮನೆ ಬಾಡಿಗೆ ಭತ್ಯೆ), ಓವರ್‌ಟೈಮ್, ಬೋನಸ್, ಕಮಿಷನ್ ಮತ್ತು ಪ್ರಯಾಣ ಭತ್ಯೆಯನ್ನು ಬಿಟ್ಟು ಉಳಿದದ್ದು. ಆದರೆ ESI ವೇತನ ಒಟ್ಟು ಸಂಬಳದ ಕನಿಷ್ಠ ಅರ್ಧದಷ್ಟು ಇರಬೇಕು. ಅದಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಕಡಿಮೆ ಇರುವಷ್ಟು ಮೊತ್ತವನ್ನು ESI ವೇತನಕ್ಕೆ ಸೇರಿಸಬೇಕು.

ದಿನಕ್ಕೆ ತುಂಬಾ ಕಡಿಮೆ ಸಂಬಳ ಪಡೆಯುವ ಸಿಬ್ಬಂದಿ ತಮ್ಮ {{ esi.employee_rate_pct }}% ಪಾಲನ್ನು ಕಟ್ಟುವುದಿಲ್ಲ. ಆದರೆ ನಿಮ್ಮ {{ esi.employer_rate_pct }}% ಪಾಲನ್ನು ನೀವು ಕಟ್ಟಲೇಬೇಕು. ಇದು ಅನ್ವಯಿಸುತ್ತದೆಯೇ ಎಂದು ತಿಳಿಯಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

ESI ಅನ್ನು ಮುಂದಿನ ತಿಂಗಳ {{ esi.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು.

ಗಮನಿಸಿ: ಈ ಲೆಕ್ಕಾಚಾರ ಅಂದಾಜು ಮೊತ್ತ ನೀಡುತ್ತದೆ. ಪೈಸೆಗಳನ್ನು ರೂಪಾಯಿಗೆ ಸರಿಪಡಿಸುವ ರೀತಿಯಿಂದ, ಅಂತಿಮ ಮೊತ್ತ ಸ್ವಲ್ಪ ಬೇರೆ ಆಗಬಹುದು. {{ site.data.facts.tools_checked_kn }}ರ ನಿಯಮಗಳ ಪ್ರಕಾರ ಪರಿಶೀಲಿಸಲಾಗಿದೆ.
