ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ESI ನೋಂದಣಿ ಬೇಕೇ?

  • {{ esi.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಉದ್ಯೋಗಿಗಳು
  • {{ esi.wage_ceiling_text }} ಅಥವಾ ಕಡಿಮೆ ತಿಂಗಳ ESI ವೇತನ: ಈ ಸಿಬ್ಬಂದಿ ಸೇರಲೇಬೇಕು

ESI (ಉದ್ಯೋಗಿಗಳ ರಾಜ್ಯ ವಿಮೆ) ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಗೆ ವೈದ್ಯಕೀಯ ಚಿಕಿತ್ಸೆ ನೀಡುತ್ತದೆ. ಅನಾರೋಗ್ಯ, ಗಾಯ ಅಥವಾ ಹೆರಿಗೆಯಿಂದ ಕೆಲಸ ಮಾಡಲು ಆಗದಿದ್ದಾಗ ಹಣದ ಸಹಾಯವನ್ನೂ ನೀಡುತ್ತದೆ. ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ {{ esi.min_employees }} ಅಥವಾ ಹೆಚ್ಚು ಉದ್ಯೋಗಿಗಳು ಇದ್ದಾಗ ESI ನೋಂದಣಿ ಮಾಡಲೇಬೇಕು. ಈ ನಿಯಮ ಎಲ್ಲ ರಾಜ್ಯಗಳಲ್ಲೂ ಒಂದೇ. ಋತುಮಾನದ ಕಾರ್ಖಾನೆಗಳಿಗೆ ESI ಅನ್ವಯಿಸುವುದಿಲ್ಲ.

ನಿಮ್ಮ ಎಲ್ಲ ಸಿಬ್ಬಂದಿಯನ್ನು ಎಣಿಸಿ:

  • ತಾತ್ಕಾಲಿಕ ಮತ್ತು ದಿನಗೂಲಿ ಸಿಬ್ಬಂದಿ
  • ಗುತ್ತಿಗೆದಾರರು ನಿಮ್ಮಲ್ಲಿ ಕೆಲಸಕ್ಕೆ ಕಳುಹಿಸುವ ಕೆಲಸಗಾರರು
  • ಹೆಚ್ಚು ಸಂಬಳದ ಸಿಬ್ಬಂದಿ

ಎಣಿಸಬೇಡಿ: ಅಪ್ರೆಂಟಿಸ್‌ಗಳು (ಅಪ್ರೆಂಟಿಸ್ ಕಾಯ್ದೆಯಡಿ ತರಬೇತಿ ಪಡೆಯುವವರು), ವ್ಯಾಪಾರದ ಮಾಲೀಕರು, ಅಥವಾ ಅದರ ಪಾಲುದಾರರು. ನಿಮ್ಮ ವ್ಯಾಪಾರ ಕಂಪನಿಯೇ? ನಿರ್ದೇಶಕರನ್ನು ಹೇಗೆ ಎಣಿಸಬೇಕು ಎಂದು ತಿಳಿಯಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

ಒಮ್ಮೆ ESI ಅನ್ವಯಿಸಿದರೆ, ಅದು ಮುಂದುವರಿಯುತ್ತದೆ. ನಂತರ ನಿಮ್ಮ ಸಿಬ್ಬಂದಿ {{ esi.min_employees }}ಕ್ಕಿಂತ ಕಡಿಮೆಯಾದರೂ ಅದು ನಿಲ್ಲುವುದಿಲ್ಲ.

ಕೆಲವು ಅಪಾಯಕಾರಿ ಕೆಲಸಗಳಿಗೆ, 1 ಉದ್ಯೋಗಿ ಇದ್ದರೂ ESI ಅನ್ವಯಿಸಬಹುದು. ಪರಿಶೀಲಿಸಲು ನಮಗೆ ಕರೆ ಮಾಡಿ.

ESI ವೇತನ ತಿಂಗಳಿಗೆ {{ esi.wage_ceiling_text }} ವರೆಗೆ ಇರುವ ಸಿಬ್ಬಂದಿ ESIನಲ್ಲಿ ಇರಲೇಬೇಕು. ESI ವೇತನ ಎಂದರೆ ತಿಂಗಳ ಸಂಬಳದಿಂದ HRA (ಮನೆ ಬಾಡಿಗೆ ಭತ್ಯೆ) ಮತ್ತು ಓವರ್‌ಟೈಮ್‌ನಂತಹ ಕೆಲವು ಭಾಗಗಳನ್ನು ಬಿಟ್ಟು ಉಳಿದದ್ದು. ಇದನ್ನು ನಾವು ನಿಮಗಾಗಿ ಪರಿಶೀಲಿಸುತ್ತೇವೆ.

ನಾವು ನಿಮಗಾಗಿ ಮಾಡುವುದು

ಕಚೇರಿಗೆ ಬರುವ ಅಗತ್ಯವಿಲ್ಲ. ಮಂಗಳೂರು, ಉಡುಪಿ ಮತ್ತು ಬೆಂಗಳೂರಿನ ವ್ಯಾಪಾರಗಳನ್ನು ನಾವು ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ.

ಮೊದಲು

ನಾವು ಪರಿಶೀಲಿಸಿ, ಕೇಳುತ್ತೇವೆ

  • ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ESI ಅನ್ವಯಿಸುತ್ತದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸುತ್ತೇವೆ, ಮತ್ತು ನಿಮ್ಮೊಂದಿಗೆ ಸಿಬ್ಬಂದಿಯನ್ನು ಎಣಿಸುತ್ತೇವೆ.
  • ನಮಗೆ ಯಾವ ದಾಖಲೆಗಳು ಬೇಕು ಎಂದು ಹೇಳುತ್ತೇವೆ. ಈ ಪಟ್ಟಿ ನಿಮ್ಮ ವ್ಯಾಪಾರದ ಬಗೆಯನ್ನು ಅವಲಂಬಿಸಿದೆ.
  • ನೀವು ಅವುಗಳನ್ನು ಇಮೇಲ್ ಮೂಲಕ ಕಳುಹಿಸಿ.

ನಂತರ

ನಿಮ್ಮ ವ್ಯಾಪಾರವನ್ನು ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ

  • ESICಯಲ್ಲಿ (ESI ಇಲಾಖೆ) ನಿಮ್ಮ ವ್ಯಾಪಾರವನ್ನು ನೋಂದಣಿ ಮಾಡುತ್ತೇವೆ.
  • ನಿಮ್ಮ ಎಲ್ಲ ದಾಖಲೆಗಳು ನಮಗೆ ಸಿಕ್ಕ ನಂತರ, ಕೆಲವೇ ಗಂಟೆಗಳಲ್ಲಿ ಮುಗಿಯುತ್ತದೆ.
  • ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ಒಂದು ESI ಕೋಡ್ ಸಂಖ್ಯೆ ಸಿಗುತ್ತದೆ. ಅದರಲ್ಲಿ 17 ಅಂಕಿಗಳಿರುತ್ತವೆ.

ಆಮೇಲೆ

ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಯನ್ನು ಸೇರಿಸುತ್ತೇವೆ

  • ನಿಯಮಗಳು ಅವರಿಗೆ ಅನ್ವಯಿಸಿದರೆ, ESIC ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ ನಿಮ್ಮ ಸಿಬ್ಬಂದಿಯನ್ನು ESIಗೆ ಸೇರಿಸುತ್ತೇವೆ.
  • ಈಗಾಗಲೇ IP ಸಂಖ್ಯೆ (ಪ್ರತಿ ಉದ್ಯೋಗಿಯ ESI ಸಂಖ್ಯೆ, ಜೀವನಪೂರ್ತಿ ಒಂದೇ ಇರುತ್ತದೆ) ಇರುವವರು ಅದನ್ನೇ ಉಳಿಸಿಕೊಳ್ಳುತ್ತಾರೆ.
  • ಉಳಿದವರಿಗೆ ನಾವು IP ಸಂಖ್ಯೆ ಮಾಡಿಕೊಡುತ್ತೇವೆ.

ನೋಂದಣಿಯ ನಂತರ

ESI ಅನ್ನು ಪ್ರತಿ ತಿಂಗಳು, ಮುಂದಿನ ತಿಂಗಳ {{ esi.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಕಟ್ಟಬೇಕು.

ಪ್ರತಿ ತಿಂಗಳು ಉದ್ಯೋಗಿ ತಮ್ಮ ESI ವೇತನದ {{ esi.employee_rate_pct }}% ಕಟ್ಟುತ್ತಾರೆ, ಮತ್ತು ನೀವು {{ esi.employer_rate_pct }}% ಕಟ್ಟುತ್ತೀರಿ. ಒಟ್ಟು {{ esi.total_rate_pct }}%. ಉದ್ಯೋಗಿಯ ಭಾಗವನ್ನು ಅವರ ಸಂಬಳದಿಂದ ಕಡಿತ ಮಾಡುತ್ತೀರಿ. ದಿನಕ್ಕೆ ತುಂಬಾ ಕಡಿಮೆ ಸಂಬಳ ಪಡೆಯುವ ಸಿಬ್ಬಂದಿ ತಮ್ಮ ಭಾಗ ಕಟ್ಟುವುದಿಲ್ಲ, ಆದರೆ ನೀವು ನಿಮ್ಮ ಭಾಗ ಕಟ್ಟಲೇಬೇಕು.

ಈ ಕೆಲಸವನ್ನು ಪ್ರತಿ ತಿಂಗಳು ನಾವು ನಿಮಗಾಗಿ ಮಾಡಬಹುದು. ನೀವು ಸಂಬಳದ ವಿವರ ಕಳುಹಿಸಿ. ನಾವು ನಿಮ್ಮ ಮಾಸಿಕ ESI ವಿವರಗಳನ್ನು ESICಗೆ ಫೈಲ್ ಮಾಡಿ, ಚಲನ್ (ESI ಪಾವತಿ ಚೀಟಿ) ಅನ್ನು ನಿಮಗೆ ಇಮೇಲ್ ಮಾಡುತ್ತೇವೆ. ಮುಂದಿನ ತಿಂಗಳ {{ esi.due_day }}ನೇ ತಾರೀಖಿನೊಳಗೆ ಅದನ್ನು ಕಟ್ಟಿ, ಅಥವಾ ಹಣವನ್ನು ನಮಗೆ ಕಳುಹಿಸಿ, ನಾವು ಕಟ್ಟುತ್ತೇವೆ.
